# 取引先ターゲット管理アプリ - 操作説明書（営業担当者向け）

**対象ロール**: `member`（担当）/ `leader`（リーダー）  
**最終更新**: 2026-07-07

---

## はじめに

本書は、営業担当者が使う「取引先ターゲット管理アプリ」の操作説明書です。本アプリは、取引先への提案活動を効率的に管理するためのツールです。日常的な活動ログ入力から月次セルフチェックまで、主要な操作手順を順番に説明します。

### アクセス方法

1. 管理者から共有された **Web アプリ URL** をブラウザ（Google Chrome 推奨）で開く
2. Googleアカウントへのアクセス許可を求めるダイアログが表示されたら「**許可**」をクリック
3. アプリが自動的に起動し、データが読み込まれます（初回は数秒かかる場合があります）

> **注意**: 自分のGoogleアカウントでログインしている必要があります。別アカウントで開くとデータが表示されません。

## 1. 画面構成

上部の**タブ**を切り替えて各機能を使います。

| タブ | 機能 | 主な用途 |
| :--- | :--- | :--- |
| 📝 活動＆アクション | 活動ログの入力・案件管理 | **毎日の主要操作** |
| 🔭 取引先ダッシュボード | 取引先別の進捗一覧 | 取引先単位で状況を確認する |
| 📊 全体サマリー＆レビュー | KPI確認・月次レビュー | 月末のセルフチェック・全体俯瞰 |
| 📈 統計 | グラフで営業状況を可視化 | 進捗状況の把握・振り返り |
| 🏥 取引先登録・編集 | 取引先・部署・案件の登録 | 新規取引先の追加・情報更新 |
| ⚙️ 設問管理 | 月次設問・キャンペーンマスターの管理 | **admin / manager のみ表示** |

> **ロールによる参照・編集範囲の違い**
>
> | ロール | 参照できる取引先 | 活動ログ・案件・取引先の編集 | 設問管理・キャンペーンマスター管理 |
> | :--- | :--- | :--- | :--- |
> | `member`（担当）・`leader`（リーダー） | 自身の担当取引先（＋担当者セレクターで他担当者の取引先を閲覧専用で参照可） | 可（自担当のみ） | 不可 |
> | `manager`（責任者） | 全登録取引先 | 不可（閲覧のみ） | **可**（⚙️設問管理タブから操作） |
> | `admin`（管理者） | 全登録取引先 | 可（取引先削除も可） | **可** |
>
> → `manager` ロールの詳細操作は [責任者向けマニュアル](MANUAL_MANAGER.md) を参照してください。

## 2. 日常操作フロー（活動ログを記録する）

### ステップ1: 対象取引先を選択する

1. 📝 **活動＆アクション** タブを開く
2. 画面上部の**取引先選択プルダウン**をクリック
3. 取引先名を入力して絞り込み、対象の取引先を選択する

> プルダウンにはキーワード検索機能があります。取引先名の一部を入力すると候補が絞られます。

> **他の担当者の取引先を閲覧したい場合**: 取引先セレクターの左隣にある**担当者セレクター**から対象者を選択すると、その担当者の取引先一覧に切り替わります。この状態ではログ入力・編集操作はできません（閲覧専用）。自分の取引先に戻る場合は担当者セレクターで「自分」を選択してください。

### ステップ2: 案件を確認する

取引先を選択すると、左側（またはページ上部）に**案件カード一覧**が表示されます。

- **赤い背景**: 次回アクション期限が超過しています。優先的に対応してください
- **左ボーダーの色**: 取引先の優先度（赤=高 / 黄=中 / グレー=低）
- **ステージバッジ**: 現在の営業進捗ステージ

### ステップ3: 活動ログを入力する

1. 右側のフォームに以下を入力します：

   | 項目 | 内容 |
   | :--- | :--- |
   | 対象案件 | プルダウンから選択（必須） |
   | 訪問日 | 実際に訪問した日付（必須） |
   | 同行者 | パートナーやベンダーが同行した場合は入力（なければ「なし」） |
   | 活動内容 | 訪問で話した内容・得られた情報（必須）。改行も反映されます |
   | ステージ | 訪問後の案件進捗ステージに更新 |
   | 次回アクション | 次にやること・期限・担当者を設定（担当者には自分以外のMRを指定することも可能） |
   | 添付ファイル | 見積書や資料があれば添付（**10MB以内**） |

   > **添付ファイルが10MBを超える場合**: Googleドライブに直接アップロードし、そのURLを活動内容欄に貼り付けてください。

2. 内容を確認したら「**ログを保存 ＋ 案件を更新**」ボタンをクリック
3. 画面右下に緑の「**保存しました ✓**」トーストが表示されれば完了

> **保存中の操作について**: 保存中は画面中央に「⏳ クラウドに保存しています...」オーバーレイが表示されます。完了するまでボタンを連打しないでください。

### ステップ4: 過去のログを編集する

過去に保存したログを修正したい場合は、案件カードの「**活動履歴**」から対象ログをクリックします。

- ヘッダーがオレンジ色に変わり「**過去のログを編集中**」と表示されます
- 修正後、「**更新する**」ボタンをクリックして保存してください
- 「**キャンセル**」を押すと新規入力モードに戻ります

### ステップ5: 案件ステージ変更履歴を確認する

案件カードの「**📋 履歴**」ボタンをクリックすると、その案件のステージ変更履歴（変更日時・ステージ・変更者）がモーダルで表示されます。

## 3. 案件の新規作成

訪問先に新しい取り組みが発生したときは案件を新規作成します。

### 方法A: 🏥 取引先登録・編集タブから作成

1. 🏥 **取引先登録・編集** タブを開く
2. 対象の取引先を選択し、「**部署一覧**」から対象部署を選ぶ
3. 「**案件を追加**」ボタンをクリック
4. 案件名（キャンペーン名）・対象製品・初期ステージを入力して保存

> **案件名（キャンペーン名）の入力について**  
> 案件名は「キャンペーンマスター」から有効期間中の候補が自動表示されます。入力欄に文字を入力すると候補が絞られます。今日の日付がキャンペーンの有効期間外の場合は候補に表示されないため、候補が出ない場合は直接テキストを入力してください。キャンペーンマスターの登録・編集は `admin`/`manager` が⚙️設問管理タブから行います。

### 方法B: クイック登録ウィザードから作成

画面ヘッダーの「**🚀 クイック登録**」ボタンで、取引先・部署・案件を1つのフローで連続登録できます。新規取引先への初回訪問時に便利です。

## 4. 案件ステージの目安

| ステージ | 意味 | 目安 |
| :---: | :--- | :--- |
| 0 | 未接触 | まだアプローチしていない |
| 1 | 接触済み | 挨拶・情報収集レベルの訪問 |
| 2 | 興味あり | 先方が関心を示している |
| 3 | 提案中 | 見積書提出・デモ実施済み |
| 4 | クロージング | 最終交渉フェーズ。結果が確定したら🏥タブで受注（won）／失注（lost）ステータスを記録する |

## 5. 取引先ダッシュボードの見方

🔭 **取引先ダッシュボード** タブでは、選択中の取引先の状況を一覧確認できます。

### 操作手順

1. 🔭 **取引先ダッシュボード** タブを開く
2. 画面上部の**取引先選択プルダウン**で確認したい取引先を選択する
3. 以下の4セクションが表示されます：

| セクション | 内容 |
| :--- | :--- |
| アクティブ案件 | 現在進行中の案件とステージ |
| クロージング実績 | 受注・失注した案件の結果 |
| 直近の訪問履歴 | 最近の活動ログ |
| 期限超過アクション | 対応が遅れているネクストアクション |

## 6. 全体サマリー＆レビュー画面の活用

📊 **全体サマリー＆レビュー** タブで月次の活動状況の確認とセルフチェックを行います。

### KPI確認

画面上部に3つのKPIが表示されます：

| KPI | 意味 |
| :--- | :--- |
| 接点部署数 | 指定月に活動ログを記録した部署の数 |
| 同行回数 | 指定月にパートナー・ベンダーと同行した訪問数 |
| 提案中案件数 | ステージ3の案件数（提案フェーズ） |

- 左右の **「＜ ＞」ボタン**で対象月を切り替えられます

### 案件一覧のフィルタリング

- **ステージフィルター**: プルダウンで特定ステージだけ表示
- **取引先名検索**: テキスト入力で取引先名を絞り込み（部分一致）

## 7. 月次セルフチェック

月末に月次セルフチェックを回答します。**📊 全体サマリー＆レビュー** タブの下部で行います。

1. 📊 **全体サマリー＆レビュー** タブを開く
2. 対象月が正しいことを確認（必要に応じて「＜ ＞」で切り替え）
3. 画面下部「**月次セルフチェック**」の各設問にチェックを入れる
4. 「**セルフチェックを保存**」ボタンをクリック

> **注意**: 設問は管理者が設定します。月によって内容が変わる場合があります。

## 8. 統計グラフを確認する

📈 **統計** タブでは、営業状況をグラフで確認できます。

### グラフの切り替え

| タブ | 表示されるグラフ |
| :--- | :--- |
| **案件概況** | ステージ別案件数（ドーナツ）・受注/失注/進行中（ドーナツ） |

> グラフのデータは初回タブ表示時に読み込まれ、キャッシュされます。最新データを取得したい場合は「🔄 更新」ボタンをクリックしてください。

## 9. データをCSVでダウンロードする

📝 **活動＆アクション** タブのツールバーに2種類のCSVボタンがあります。

### 📊 データCSV出力

取引先・案件・期間を絞り込んで**18列の統一フォーマット**でダウンロードできます。

1. 「📊 データCSV出力」ボタンをクリックしてモーダルを開く
2. ① **取引先**を選択（「全取引先」または特定の取引先）
3. ② **案件**を選択（テキスト入力で絞り込み可。「全案件」でも可）
4. ③ **期間**を選択（全件 / 直近1ヶ月 / 期間指定）
5. 「📥 CSV出力」をクリック

**出力列（18列）**: 担当者名・取引先コード・取引先名・担当MS・部署名・案件名・対象製品・進捗ステージ・受注/失注・最新課題メモ・ネクストアクション・アクション担当者・次回予定日・訪問日・活動内容・同行者・添付URL・更新日時

> **期間フィルターについて**: 期間の絞り込みは活動ログ行にのみ適用されます。選択した取引先・案件は必ず出力されます（期間内のログがない案件は案件情報のみ1行で出力）。

- `member`/`leader` は自担当取引先のデータのみ出力されます
- `manager`/`admin` は全担当者分が出力されます
- ファイルは BOM付きUTF-8 形式のため、Excel でそのまま開いても文字化けしません

### 📊 案件別進捗レポート（全体）

キャンペーン名（案件名）で絞り込み、全担当者の進捗＋活動履歴を出力します。ロール問わず**全登録ユーザーが利用可能**です。

1. 「📊 案件別進捗レポート（全体）」ボタンをクリック
2. ダイアログが開くのでキャンペーン名を入力（一部入力でサジェストが表示されます）
3. 「📥 CSV出力」ボタンをクリック

## 10. よくある質問

**Q. データが表示されない / 古いデータが表示される**  
A. ブラウザをリロード（F5）してください。初回読み込み時にすべてのデータをGASから取得します。

**Q. 保存しようとしたら「エラーが発生しました」と表示された**  
A. エラーダイアログの「**再試行**」ボタンをクリックしてください。GASのタイムアウトによる一時的なエラーは再試行で解決することがほとんどです。繰り返す場合は管理者に連絡してください。

**Q. 自分で登録した取引先がリストに表示されない**  
A. `member`・`leader` ロールでは、ご自身が登録した取引先のみリストに表示されます（登録時に自分のアカウントが紐付けられます）。登録済みにもかかわらず表示されない場合は、まずブラウザをリロード（F5）してください。それでも解決しない場合はアプリの不具合の可能性があるため、管理者に連絡してください。

**Q. キャンペーン名（案件名）のプルダウンに候補が出ない**  
A. キャンペーンマスターに登録された有効期間外の場合、候補に表示されません。候補が出ない場合は直接テキストを入力してください。キャンペーンの期間設定は管理者が行います。

**Q. スマートフォンから使える？**  
A. iPhoneおよびAndroidのGoogle Chromeブラウザで閲覧可能です。操作性はPC推奨です。
