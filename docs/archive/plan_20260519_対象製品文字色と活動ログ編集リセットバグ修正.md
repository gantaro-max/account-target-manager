# 実装指示書 - 対象製品文字色調整 & 活動ログ編集リセットバグ修正

**作成日**: 2026-05-19
**対象ブランチ**: main
**担当**: Codex

---

## 1. 概要

2件の修正を行う。

1. **文字色調整**: 各画面の対象製品表示が薄すぎるため `var(--muted)` → `var(--gray)` に変更
2. **バグ修正**: 活動ログ編集中に別の取引先を選択しても編集モードが解除されない

---

## 2. 修正① 対象製品の文字色調整

### 変更対象・箇所

`color:var(--muted)` → `color:var(--gray)` に一括置換する。対象は `targetProduct` の表示スパンのみ。

| ファイル | 行 |
| :--- | :--- |
| `src/js.html` | 209行、225行 |
| `src/js_log.html` | 272行、395行 |

各ファイルで以下のパターンを置換する（2ファイルとも同じパターン）：

```
// 変更前
color:var(--muted); font-weight:normal; margin-left:6px;

// 変更後
color:var(--gray); font-weight:normal; margin-left:6px;
```

`replace_all=True` で各ファイルを処理すること（各ファイル内に複数箇所あるため）。

## 3. 修正② 活動ログ編集リセットバグ

### 原因

`changeAccount(tabIdx, id)` （`src/js_account.html` 75行付近）が取引先切り替え時に `renderAll()` を呼ぶが、`cancelEditLog()` を呼ばないため `editingLogId` が残ったまま再描画される。

### 変更対象

`src/js_account.html` の `changeAccount()` 関数内、`renderAll()` の直前に1行追加する。

```javascript
// 変更前
    renderAll();
    if (tabIdx === 0)

// 変更後
    if (tabIdx === 0 && typeof cancelEditLog === "function") cancelEditLog();
    renderAll();
    if (tabIdx === 0)
```

### 補足

- `typeof cancelEditLog === "function"` のガードはロード順の安全策（`cancelEditLog` は `js_log.html` で定義）。
- `tabIdx === 0` のとき（活動ログタブ対象取引先の変更）のみリセットする。他のタブ（1, 3）は対象外。
