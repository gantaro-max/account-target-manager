# 実装指示書: 案件進捗レポート CSV出力 — 全ロール開放 & UI移動

**作成日**: 2026-06-10  
**対象ブランチ**: feature/advance

---

## 背景・目的

現在 `getProjectReport()` は `_requireManager()` で制限されており、UIも Tab 3（📈 統計）の `admin-only` カードに隠れている。  
キャンペーンの推進責任者が `member` / `leader` ロールに関わらず存在するため、**全ロールが実行できる**ように開放する。  
あわせて UI を Tab 0（📝 活動＆アクション）のツールバーに移動し、スクロールを発生させない SweetAlert2 ダイアログ方式に変更する。

## 3. `src/js_log.html` の変更

### 変更箇所

既存の `downloadProjectReportCsv()` 関数全体を以下に**置き換える**。  
`$("report-query")` への参照をなくし、SweetAlert2 の `html` モードで入力欄と datalist をダイアログ内に生成する。

```javascript
function downloadProjectReportCsv() {
  Swal.fire({
    title: "📊 案件進捗レポート出力",
    html:
      '<input type="text" id="swal-report-query" list="swal-report-datalist"' +
      ' placeholder="案件名を入力（部分一致）"' +
      ' style="width:100%; padding:6px 8px; border:1px solid #ccc; border-radius:4px; font-size:14px;">' +
      '<datalist id="swal-report-datalist"></datalist>',
    didOpen: function () {
      var dl = document.getElementById("swal-report-datalist");
      (db.activePlans || []).forEach(function (campaign) {
        var opt = document.createElement("option");
        opt.value = campaign.name;
        dl.appendChild(opt);
      });
      document.getElementById("swal-report-query").focus();
    },
    showCancelButton: true,
    confirmButtonText: "📥 CSV出力",
    cancelButtonText: "キャンセル",
    preConfirm: function () {
      var query = (
        document.getElementById("swal-report-query").value || ""
      ).trim();
      if (!query) {
        Swal.showValidationMessage("案件名・キャンペーン名を入力してください。");
        return false;
      }
      return query;
    },
  }).then(function (result) {
    if (!result.isConfirmed) return;
    var query = result.value;
    Swal.fire({
      title: "CSV出力中...",
      allowOutsideClick: false,
      didOpen: function () {
        Swal.showLoading();
      },
    });
    google.script.run
      .withSuccessHandler(function (csv) {
        Swal.close();
        if (!csv) {
          Swal.fire(
            "該当なし",
            "条件に一致する案件が見つかりませんでした。",
            "info",
          );
          return;
        }
        var blob = new Blob([csv], { type: "text/csv;charset=utf-8;" });
        var url = URL.createObjectURL(blob);
        var a = document.createElement("a");
        a.href = url;
        a.download =
          "案件進捗レポート_" +
          query +
          "_" +
          new Date().toISOString().slice(0, 10) +
          ".csv";
        document.body.appendChild(a);
        a.click();
        setTimeout(function () {
          document.body.removeChild(a);
          URL.revokeObjectURL(url);
        }, 100);
      })
      .withFailureHandler(function (e) {
        Swal.fire("エラー", e.message, "error");
      })
      .getProjectReport(query);
  });
}
```

### ポイント

- `didOpen` で `db.activePlans` から datalist を動的生成（既存の `populateCampaignDatalist()` と同じデータソース）
- ダイアログが開いたら入力欄に自動フォーカスする
- 未入力で確定しようとすると `Swal.showValidationMessage()` でインラインエラーを表示する
- CSV出力ボタン押下後は別の「出力中...」ダイアログに切り替わる（既存 `downloadCsv` と同パターン）

## 4. `src/js_project.html` の変更

### 変更箇所

`populateCampaignDatalist()` 内の `forEach` から `"report-campaign-datalist"` を削除する。  
`id="report-campaign-datalist"` の要素は HTML から削除済みのため、参照すると `null` になる。

```javascript
// 変更前
function populateCampaignDatalist() {
  ["campaign-datalist", "report-campaign-datalist"].forEach(function (id) {
    const datalist = $(id);
    if (!datalist) return;
    datalist.innerHTML = "";
    (db.activePlans || []).forEach(function (campaign) {
      const option = document.createElement("option");
      option.value = campaign.name;
      if (campaign.description) option.label = campaign.description;
      datalist.appendChild(option);
    });
  });
}

// 変更後
function populateCampaignDatalist() {
  const datalist = $("campaign-datalist");
  if (!datalist) return;
  datalist.innerHTML = "";
  (db.activePlans || []).forEach(function (campaign) {
    const option = document.createElement("option");
    option.value = campaign.name;
    if (campaign.description) option.label = campaign.description;
    datalist.appendChild(option);
  });
}
```

## UI フロー

```
[Tab 0 を開く]
  ↓
[ツールバー右端に「📊 案件進捗レポート」ボタンが表示される（全ロール）]
  ↓
[ボタンをクリック]
  ↓
[SweetAlert2 ダイアログが開く]
  │  タイトル: 📊 案件進捗レポート出力
  │  入力欄: 案件名を入力（部分一致）  ← datalist サジェスト付き
  │  [キャンセル] [📥 CSV出力]
  ↓
  ├─ キャンセル → ダイアログを閉じる
  ├─ 未入力で CSV出力 → 入力欄下にバリデーションエラー表示
  └─ 入力あり → 「CSV出力中...」ローディングダイアログ
       ↓
       ├─ 0件一致 → 「該当なし」ダイアログ
       └─ 1件以上 → CSV ダウンロード
```
