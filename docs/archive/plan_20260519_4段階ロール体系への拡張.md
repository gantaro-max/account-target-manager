# 実装指示書 - 4段階ロール体系への拡張

**作成日**: 2026-05-19
**対象ブランチ**: main
**担当**: Codex

---

## 1. 概要

現在の3段階ロール（`admin` / `leader` / `member`）を4段階（`admin` / `manager` / `leader` / `member`）に拡張する。

**ロール体系:**

| ロール値 | 表示名 | 変更内容 |
|---|---|---|
| `admin` | 管理者 | 変更なし（最上位） |
| `manager` | 責任者 | **新設**（旧 `leader` を昇格・改名） |
| `leader` | リーダー | **新設**（中間層。旧 `leader` より権限を縮小） |
| `member` | 担当 | 変更なし |

**変更対象ファイル**: `src/index.html` / `src/コード_v2_9.js` / `src/js.html` の3ファイル。

## 5. `src/コード_v2_9.js` の変更

### 5-1. `_requireManager()` ヘルパーの追加

`_requireAdmin()` 関数の直後に追加する。

```javascript
// 変更前
function _requireAdmin() {
  if (_getMyRole() !== "admin")
    throw new Error("この操作には管理者権限が必要です");
}

// 変更後
function _requireAdmin() {
  if (_getMyRole() !== "admin")
    throw new Error("この操作には管理者権限が必要です");
}
function _requireManager() {
  const r = _getMyRole();
  if (r !== "admin" && r !== "manager")
    throw new Error("この操作には責任者以上の権限が必要です");
}
```

## 7. 補足・注意事項

- `_requireAdmin()` は **削除しない**。`admin` 専用操作（`deleteAccountWithCascade` 等）のために維持する。
- フロントエンドの非表示制御はあくまで UI レベルの制御。実際の保護は GAS 側の `_requireManager()` / `_requireAdmin()` が担う。
- `manager` が Tab 3 を非表示にされた状態で `switchTab(3)` を直接呼び出した場合の対策は今回のスコープ外（GAS 側権限チェックで対応済み）。
