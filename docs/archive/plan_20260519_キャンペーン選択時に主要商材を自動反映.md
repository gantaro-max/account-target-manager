# 実装指示書 - キャンペーン選択時に対象製品を自動反映

**作成日**: 2026-05-19
**対象ブランチ**: main
**担当**: Codex

---

## 1. 概要

案件名フィールドでキャンペーンを選択したとき、そのキャンペーンの `item` 値を対象製品フィールドに自動入力する。

- 対象フィールドペア①: `new-proj-name` → `new-proj-target`（取引先登録・編集タブ）
- 対象フィールドペア②: `qa-proj-name` → `qa-proj-target`（連鎖モーダル）
- `campaigns` シートは引き続き読み取り専用。`db.activePlans` を参照するのみ。

## 3. 実装詳細

### 3.1 `onCampaignNameInput()` を追加（`src/js_project.html`）

`populateCampaignDatalist()` 関数の直後に追加する。

```javascript
function onCampaignNameInput(nameFieldId, targetFieldId) {
  const name = $(nameFieldId).value;
  const campaign = (db.activePlans || []).find(function (p) {
    return p.name === name;
  });
  if (campaign && campaign.item) {
    $(targetFieldId).value = campaign.item;
  }
}
```

**動作仕様**:
- datalist から選択されると `oninput` が発火し、入力値がキャンペーン名と完全一致する場合のみ対象製品を自動入力する
- 自由入力中は完全一致しないため、自動入力は発生しない
- `item` が空のキャンペーンを選択した場合は対象製品フィールドを変更しない（ユーザーが手入力した値を保持）

### 3.2 `new-proj-name` に `oninput` を追加（`src/index.html`）

<input
  type="text"
  id="new-proj-name"
  list="campaign-datalist"
  placeholder="案件を入力"
