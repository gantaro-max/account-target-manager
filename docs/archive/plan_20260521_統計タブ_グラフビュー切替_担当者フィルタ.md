# 実装指示書: 統計タブ グラフビュー切替 & 担当者フィルタ

作成日: 2026-05-21

---

## 概要

統計タブのグラフ表示を「全グラフ同時表示」から「2タブ切替 + 担当者フィルタ」形式に刷新する。

---

## 変更対象ファイル

- `src/コード_v2_9.js`
- `src/index.html`
- `src/js_stats.html`
- `src/css.html`

---

## 機能要件

### タブ切替（全ユーザー共通）

| タブ | 表示グラフ | グリッド列数 |
|------|-----------|------------|
| **案件概況** | ①ステージ別案件数（ドーナツ）+ ②受注/失注/進行中（ドーナツ） | 2列均等 |
| **活動状況** | ③月別活動件数（縦棒）＋ ④担当者別案件数（横棒）| 2列均等 ※条件あり |

- デフォルト表示タブは「案件概況」
- タブ切替は API 再呼び出し不要（既取得データで表示切替のみ）

### 担当者別グラフ④の表示条件

- `isAll === true`（admin / manager）かつ担当者セレクトが「全体」のときのみ表示
- 一般ユーザー、または個人選択時は非表示 → ③が全幅（1列）表示

### 担当者フィルタセレクト（admin / manager のみ）

- コントロールバー右側に表示
- 選択肢: 「全体」（`value=""`）＋ユーザー一覧（`value=uid`）
- ユーザー一覧は初回ロード時に取得した `data.userCounts`（uid・name を含む）から生成
- セレクト変更時: `_statsTargetUser` を更新し `reloadStats()` を呼び出す
- 個人選択時は担当者別グラフ④を非表示にし③を全幅で表示する

## 変更詳細

### 1. `src/コード_v2_9.js` — `getStatistics()` の改修

#### 変更点

**関数シグネチャに引数を追加**

```js
function getStatistics(targetUserId) {
```

**フィルタ用メールアドレスの決定ロジックを追加**（既存の `isAll` 定義の直後に追加）

```js
// 表示対象メールの決定
// - 一般ユーザー: 常に自分のデータ
// - admin/manager で targetUserId 指定あり: 対象ユーザーのデータ
// - admin/manager で targetUserId 指定なし: 全ユーザー（null = フィルタなし）
let filterEmail = null;
if (!isAll) {
  filterEmail = email;
} else if (targetUserId) {
  filterEmail = targetUserId;
}
```

**accounts フィルタを `filterEmail` 対応に変更**

```js
// 変更前
.filter((h) => isAll || h.assigned_user_id === email)

// 変更後
.filter((h) => filterEmail === null || h.assigned_user_id === filterEmail)
```

**`userCounts` 算出を全件データから行うよう変更**

担当者フィルタ中でも担当者セレクトの選択肢が消えないよう、`userCounts` は常に
全取引先データ（`_getRows(SHEET.ACCOUNTS)` の未フィルタ版）を使用すること。

現在の実装では `accounts`（フィルタ済み）を使っているため、以下のように修正する:

```js
if (isAll) {
  const allAccounts = _getRows(SHEET.ACCOUNTS); // ← フィルタなし全件
  const users = _getRows(SHEET.USERS);
  const userNameMap = {};
  users.forEach((u) => {
    userNameMap[u.user_id] = u.name || u.user_id;
  });
  const countMap = {};
  allAccounts.forEach((h) => {
    if (h.assigned_user_id && !(h.assigned_user_id in countMap)) {
      countMap[h.assigned_user_id] = 0;
    }
  });
  _getRows(SHEET.PROJECTS).forEach((p) => {
    const hosp = allAccounts.find((h) => h.id === p.account_id);
    if (!hosp || !hosp.assigned_user_id) return;
    if (!(hosp.assigned_user_id in countMap)) countMap[hosp.assigned_user_id] = 0;
    countMap[hosp.assigned_user_id]++;
  });
  userCounts = Object.entries(countMap)
    .map(([uid, count]) => ({ name: userNameMap[uid] || uid, uid, count })) // uid を追加
    .sort((a, b) => b.count - a.count);
}
```

`return` オブジェクトに変更なし。

### 4. `src/js_stats.html` — JS全面改修

既存コードを以下に**全置き換え**する。

```js
// ── 統計タブ ─────────────────────────────────────────────────────────────

let _statsLoaded = false;
const _statsCharts = {};
let _statsView = "overview";       // 現在のタブ
let _statsTargetUser = "";         // "" = 全体、それ以外はuid
let _statsIsAll = false;           // admin/manager フラグ（初回ロード後に確定）

const STAGE_COLORS = ["#94a3b8", "#3b82f6", "#f59e0b", "#0891b2", "#22c55e"];

function initStatsTab() {
  if (_statsLoaded) return;
  const loading = $("stats-loading");
  const grid = $("stats-grid");
  if (loading) { loading.textContent = "読み込み中..."; loading.style.display = "block"; }
  if (grid) grid.style.display = "none";

  google.script.run
    .withSuccessHandler((data) => {
      _statsLoaded = true;
      _statsIsAll = data.isAll;
      if (loading) loading.style.display = "none";
      if (grid) grid.style.display = "grid";
      _renderStats(data);
      _applyView();
    })
    .withFailureHandler((e) => {
      if (loading) loading.textContent = "読み込みエラー: " + e.message;
    })
    .getStatistics(_statsTargetUser || null);
}

function reloadStats() {
  _statsLoaded = false;
  Object.values(_statsCharts).forEach((c) => { if (c) c.destroy(); });
  Object.keys(_statsCharts).forEach((k) => delete _statsCharts[k]);
  initStatsTab();
}

// タブ切替（API再呼び出しなし）
function switchStatsView(view) {
  _statsView = view;
  document.querySelectorAll(".stats-tab").forEach((btn, i) => {
    btn.classList.toggle("active", (i === 0 && view === "overview") || (i === 1 && view === "activity"));
  });
  _applyView();
}

// 担当者セレクト変更
function onStatsUserChange() {
  _statsTargetUser = $("stats-user-select").value;
  reloadStats();
}

// ビュー状態をDOMに反映
function _applyView() {
  const isOverview = _statsView === "overview";
  const showUsers = _statsIsAll && _statsTargetUser === "";

  // カード表示切替
  document.querySelectorAll(".stats-card-overview").forEach((el) => {
    el.style.display = isOverview ? "flex" : "none";
  });
  document.querySelectorAll(".stats-card-activity").forEach((el) => {
    el.style.display = !isOverview ? "flex" : "none";
  });

  // 担当者別グラフは条件付き
  const usersCard = $("chart-users-card");
  if (usersCard) usersCard.style.display = (!isOverview && showUsers) ? "flex" : "none";

  // グリッド列数: 活動状況タブで担当者別非表示なら1列
  const grid = $("stats-grid");
  if (grid) {
    const oneCol = !isOverview && !showUsers;
    grid.style.gridTemplateColumns = oneCol ? "1fr" : "1fr 1fr";
  }

  // Chart.js に再描画を促す
  Object.values(_statsCharts).forEach((c) => { if (c) c.resize(); });
}

function _renderStats(data) {
  // ① ステージ別案件数
  _statsCharts.stage = new Chart($("chart-stage"), {
    type: "doughnut",
    data: {
      labels: STAGE_LABELS,
      datasets: [{
        data: ["0","1","2","3","4"].map((s) => data.stageCounts[s] || 0),
        backgroundColor: STAGE_COLORS,
        borderWidth: 1,
        borderColor: "#fff",
      }],
    },
    options: {
      maintainAspectRatio: false,
      plugins: { legend: { position: "bottom" } },
      cutout: "60%",
    },
  });

  // ② 受注/失注/進行中
  _statsCharts.closing = new Chart($("chart-closing"), {
    type: "doughnut",
    data: {
      labels: ["進行中", "受注", "失注"],
      datasets: [{
        data: [data.closing.inProgress, data.closing.won, data.closing.lost],
        backgroundColor: ["#3b82f6", "#22c55e", "#ef4444"],
        borderWidth: 1,
        borderColor: "#fff",
      }],
    },
    options: {
      maintainAspectRatio: false,
      plugins: { legend: { position: "bottom" } },
      cutout: "60%",
    },
  });

  // ③ 月別活動件数
  _statsCharts.monthly = new Chart($("chart-monthly"), {
    type: "bar",
    data: {
      labels: data.monthlyLogs.map((m) => m.month),
      datasets: [{
        label: "活動件数",
        data: data.monthlyLogs.map((m) => m.count),
        backgroundColor: "rgba(8,145,178,0.7)",
        borderRadius: 4,
      }],
    },
    options: {
      maintainAspectRatio: false,
      plugins: { legend: { display: false } },
      scales: { y: { beginAtZero: true, ticks: { stepSize: 1 } } },
    },
  });

  // ④ 担当者別案件数（admin/manager のみ）
  if (data.isAll && data.userCounts && data.userCounts.length > 0) {
    const userCanvas = $("chart-users");
    const dynamicH = Math.max(200, data.userCounts.length * 36 + 48);
    userCanvas.style.flex = "none";
    userCanvas.style.height = dynamicH + "px";

    _statsCharts.users = new Chart(userCanvas, {
      type: "bar",
      data: {
        labels: data.userCounts.map((u) => u.name),
        datasets: [{
          label: "案件数",
          data: data.userCounts.map((u) => u.count),
          backgroundColor: "rgba(15,23,42,0.7)",
          borderRadius: 4,
        }],
      },
      options: {
        maintainAspectRatio: false,
        indexAxis: "y",
        plugins: { legend: { display: false } },
        scales: { x: { beginAtZero: true, ticks: { stepSize: 1 } } },
      },
    });

    // 担当者セレクトを生成（初回ロード 全体 時のみ選択肢を更新）
    if (_statsTargetUser === "") {
      _buildUserSelect(data.userCounts);
    }
    $("stats-user-filter").style.display = "flex";
  }
}

// 担当者セレクトの選択肢を生成
function _buildUserSelect(userCounts) {
  const sel = $("stats-user-select");
  if (!sel) return;
  sel.innerHTML = '<option value="">全体</option>';
  userCounts.forEach((u) => {
    const opt = document.createElement("option");
    opt.value = u.uid;
    opt.textContent = u.name;
    if (u.uid === _statsTargetUser) opt.selected = true;
    sel.appendChild(opt);
  });
}
```

## 完了条件 (Definition of Done)

- [ ] **一般ユーザー**: タブが2つ表示され、案件概況タブに①②が2列表示、活動状況タブに③が全幅表示される。担当者セレクトは表示されない。

- [ ] 担当者選択変更時はAPIを再呼び出しし、グラフが正しく再描画される。
- [ ] 🔄 更新ボタンで全グラフが再取得・再描画される。
