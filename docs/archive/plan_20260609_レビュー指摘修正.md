#### A-1【Critical】XSS: `openStageHistory` の `h.changedBy` / `h.changedAt` / `h.stage` をエスケープせず innerHTML に連結している

**ファイル**: `src/js_log.html`  
**該当箇所**: `openStageHistory` 関数内の `el.innerHTML = ...` ブロック（`h.changedBy` / `h.changedAt` / `h.stage` を直接連結している部分）

**修正内容**: innerHTML に挿入する前に `_escapeHtml()` でエスケープする。`_escapeHtml` は後述の A-2 で `js_core.html` に追加する。

修正後のテーブル行生成部分（map 内）を以下に置き換える:

```js
history.map(function (h) {
  const safeAt = _escapeHtml(h.changedAt);
  const safeStage = _escapeHtml(String(h.stage));
  const safeBy = _escapeHtml(h.changedBy);
  const stageLabel = _escapeHtml(
    STAGE_LABELS[parseInt(h.stage, 10)] != null
      ? STAGE_LABELS[parseInt(h.stage, 10)]
      : h.stage
  );
  return (
    '<tr>' +
    '<td style="padding:6px 8px;font-size:12px;border-bottom:1px solid #f0f0f0;">' + safeAt + '</td>' +
    '<td style="padding:6px 8px;font-size:12px;border-bottom:1px solid #f0f0f0;">' +
      '<span class="stage stage-' + safeStage + '">' + stageLabel + '</span>' +

    '</tr>'
```

#### A-2【Critical】共通 HTML エスケープ関数を `js_core.html` に追加し、各モジュールの重複定義を削除する

**ファイル**: `src/js_core.html`（追加）・`src/js_review.html`（削除）・`src/js_stats.html`（削除）

**背景**: `_escapeCampaignHtml` (js_review.html) と `_escapeHtml` (js_stats.html) が完全に同一のロジックを重複定義している。また `_escapeCampaignAttr`・`_escapeAttr` は引数をそのまま渡すだけの無意味なラッパーである。

**js_core.html に追加** (既存の `db` オブジェクト定義の直後あたりに追加):

```js
function _escapeHtml(value) {
  return String(value == null ? "" : value)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#39;");
}
```

**js_review.html から削除**:
- `_escapeCampaignHtml` 関数の定義（5行のreplace チェーン）
- `_escapeCampaignAttr` 関数の定義（`return _escapeCampaignHtml(value)` のラッパー）
- `_escapeCampaignAttr` の呼び出し箇所を `_escapeHtml` に置き換える
- `_escapeCampaignHtml` の呼び出し箇所を `_escapeHtml` に置き換える

**js_stats.html から削除**:
- `_escapeHtml` 関数の定義（既存のローカル定義）
- `_escapeAttr` 関数の定義（`return _escapeHtml(value)` のラッパー）
- `_escapeAttr` の呼び出し箇所を `_escapeHtml` に置き換える

> ※ `js_core.html` はすべてのモジュールより先に読み込まれるため、グローバル関数として全ファイルから参照できる。

#### B-1【Critical】競合状態: `reloadStats` を素早く2回押すと同一 canvas に Chart.js を二重生成する

**ファイル**: `src/js_stats.html`  
**問題**: `withSuccessHandler` コールバック内で直接 `_renderStats()` を呼んでいるため `_statsLoaded` フラグのチェックをバイパスする。  

**修正**: `initStatsTab` にインフライトフラグを追加する。

```js
let _statsLoading = false; // ← 追加（ファイル先頭の変数宣言に追加）

function initStatsTab() {
  if (_statsLoaded) {
    _applyStatsView();
    return;
  }
  if (_statsLoading) return; // ← 追加: 二重呼び出しをブロック
  _statsLoading = true;      // ← 追加

  const loading = $("stats-loading");
  const grid = $("stats-grid");
  if (loading) {
    loading.textContent = "読み込み中...";
    loading.style.display = "block";
  }
  if (grid) grid.style.display = "none";

  google.script.run
    .withSuccessHandler((data) => {
      _statsLoading = false; // ← 追加
      _statsLoaded = true;
      _statsLastData = data;
      if (loading) loading.style.display = "none";
      if (grid) grid.style.display = "grid";
      _renderStats(data);
    })
    .withFailureHandler((e) => {
      _statsLoading = false; // ← 追加: 失敗時もフラグをリセット
      if (loading) loading.textContent = "読み込みエラー: " + e.message;
    })
    .getStatistics(_statsTargetUser);
}

function reloadStats() {
  _statsLoaded = false;
  _statsLoading = false; // ← 追加: 強制リセット
  _statsLastData = null;
  Object.values(_statsCharts).forEach((chart) => {
    if (chart) chart.destroy();
  });
  Object.keys(_statsCharts).forEach((key) => delete _statsCharts[key]);
  if ($("chart-users-card")) $("chart-users-card").style.display = "none";
  initStatsTab();
}
```

#### D-2【Medium】`_appendStageHistory` が毎回 `SHEET.USERS` を読み込む — `syncMyData` のループで N 件のステージ変更時に N 回読み込まれる

**ファイル**: `src/コード_v2_9.js`  
**問題**: `_appendStageHistory` は内部で `_getRows(SHEET.USERS)` を呼ぶため、`syncMyData` のように複数回呼ばれる文脈では N 回の API コールが発生する。

**修正方針**: `_appendStageHistory` にオプションの `userNameMap` 引数を追加し、呼び出し元でマップを渡せるようにする。

```js
// 修正後の _appendStageHistory
function _appendStageHistory(projectId, accountId, stage, changedBy, userNameMap) {
  let displayName = changedBy;
  if (userNameMap) {
    displayName = userNameMap[changedBy] || changedBy;
  } else {
    const users = _getRows(SHEET.USERS);
    const user = users.find((u) => u.user_id === changedBy);
    displayName = user && user.name ? user.name : changedBy;
  }
  _appendRow(SHEET.STAGE_HISTORY, {
    id: Utilities.getUuid(),
    project_id: projectId,
    account_id: accountId,
    stage: String(stage),
    changed_at: new Date(),
    changed_by: displayName,
  });
}
```

`syncMyData` 内のステージ変更ループの前で `userNameMap` を構築し、ループ内で渡す:

```js
// ループの直前に追加

// ループ内を修正 (userNameMap を第5引数に渡す)
(snapshot.projects || []).forEach((p) => {
```
