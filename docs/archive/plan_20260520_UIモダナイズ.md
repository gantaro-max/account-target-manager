# 実装指示書：UIモダナイズ（影・グロー・フォント刷新）

- **作成日**: 2026-05-20
- **対象ファイル**: `src/css.html` のみ
- **機能変更**: なし（純粋なスタイル改善）

---

## 背景・目的

現在の UI はレイアウトや色の方向性は正しいが、カードが「白い平面」に溶け込んでいて奥行き感が不足している。
ユーザーのモチベーション向上を目的に、以下の3点を中心に CSS のみを修正する。

1. **日本語フォントの追加**（Noto Sans JP）
2. **カード・コンポーネントへの影追加**（奥行き・浮遊感）
3. **インタラクションの質感向上**（入力フォーカスグロー、ボタンのリフトアップ）

---

## 変更内容（`src/css.html`）

### 1. Google Fonts インポート行を更新（1行目付近）

**変更前:**
```css
@import url("https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500;600&family=DM+Mono:wght@400;500&display=swap");
```

```css
@import url("https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500;600&family=DM+Mono:wght@400;500&family=Noto+Sans+JP:wght@400;500;600&display=swap");
```
