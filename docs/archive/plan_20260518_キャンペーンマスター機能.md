## 1. 概要

年間を通じた「重点取組（キャンペーン）」マスターテーブルを新規追加し、案件の「案件名」入力欄をコンボボックス（選択 or 自由入力）に変更する。

**変更の本質**:
- データ構造: `campaigns` シートを新規追加するのみ。`projects` シートへのカラム追加は不要。
- UI: 案件フォームの案件名フィールドを `<datalist>` を使ったコンボボックスに変更。
- GAS: 期間中のキャンペーン一覧を返す新関数 `getActivePlans()` を追加。

## 4. GAS実装（`src/コード_v2_9.js`）

### 4.1 追加関数 `getActivePlans()`

既存の `getSheetData()` ヘルパーと同じパターンで実装する。

```javascript
function getActivePlans() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('campaigns');
  if (!sheet) return [];

  const today = new Date();
  today.setHours(0, 0, 0, 0);

  const rows = sheet.getDataRange().getValues();
  const headers = rows[0];
  const idxName      = headers.indexOf('name');
  const idxStartDate = headers.indexOf('start_date');
  const idxEndDate   = headers.indexOf('end_date');
  const idxDesc      = headers.indexOf('description');

  const result = [];
  for (let i = 1; i < rows.length; i++) {
    const row = rows[i];
    if (!row[idxName]) continue; // 名前が空の行はスキップ

    const start = row[idxStartDate] ? new Date(row[idxStartDate]) : null;
    const end   = row[idxEndDate]   ? new Date(row[idxEndDate])   : null;

    // 開始日・終了日が未設定の場合は常に表示。設定済みの場合は期間内のみ。
    const isActive = (!start || start <= today) && (!end || end >= today);
    if (!isActive) continue;

    result.push({
      name:        String(row[idxName]),
      description: idxDesc >= 0 ? String(row[idxDesc] || '') : ''
    });
  }
  return result;
}
```

## 5. フロントエンド実装

### 5.1 State への追加（`src/js_core.html`）

`State` オブジェクトの初期値に `activePlans` を追加する。

```javascript
// 既存の State オブジェクト内に追加
activePlans: [],  // { name, description }[] - 期間中のキャンペーン一覧
```

### 5.2 初期化時にキャンペーンリストを取得（`src/js.html`）

アプリ初期化処理（`initializeApp()` または同等の関数）内で `getActivePlans()` を呼び出し、Stateに格納する。既存の初期化フローに **並列で** 追加すること（直列にして遅延させない）。

```javascript
// 既存の初期化呼び出しに追記
google.script.run
  .withSuccessHandler(function(campaigns) {
    State.activePlans = campaigns || [];
  })
  .withFailureHandler(function(e) {
    console.warn('キャンペーンリスト取得失敗:', e);
    State.activePlans = [];
  })
  .getActivePlans();
```

### 5.3 案件フォームの案件名フィールドをコンボボックス化（`src/js.html`）

#### HTML変更

案件名の `<input type="text">` を以下の形式に変更する。既存の `id` および `name` 属性は維持すること。

```html
<!-- 変更前 -->
<input type="text" id="project-name" ...>

<!-- 変更後 -->
<input type="text" id="project-name" list="campaign-datalist" 
       placeholder="キャンペーンを選択または入力" autocomplete="off" ...>
<datalist id="campaign-datalist"></datalist>
```

#### datalist の動的生成

案件フォームを **開く直前**（モーダル表示関数または案件編集関数内）で以下を実行し、datalistを最新のキャンペーンリストで更新する。

```javascript
function populateCampaignDatalist() {
  const datalist = document.getElementById('campaign-datalist');
  if (!datalist) return;
  datalist.innerHTML = '';
  (State.activePlans || []).forEach(function(campaign) {
    const option = document.createElement('option');
    option.value = campaign.name;
    if (campaign.description) option.label = campaign.description;
    datalist.appendChild(option);
  });
}
```

案件フォームを開く処理の冒頭で `populateCampaignDatalist()` を呼び出す。

## 6. UIフロー

```
案件フォームを開く
  ↓
populateCampaignDatalist() 実行（State.activePlansからdatalistを生成）
  ↓
ユーザーが「案件名」フィールドをクリック
  ↓
  ┌─ 期間中のキャンペーンリストがドロップダウンに表示される
  │   → 選択するとフィールドにキャンペーン名が入力される
  └─ リストにない場合はそのまま自由入力できる
  ↓
既存の保存処理（案件Upsert）をそのまま実行
（projects.name に入力値が格納される）
```

## 8. 注意事項

- `campaigns` シートが存在しない環境（本番適用前）では `getActivePlans()` が空配列を返す実装にすること（エラーで落ちない）。
- datalistはブラウザ標準UIのため、スタイルのカスタマイズは最小限にとどめる。
- 既存の案件名バリデーション（必須チェック等）はそのまま維持すること。
