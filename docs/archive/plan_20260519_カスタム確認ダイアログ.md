# 実装指示書: 取引先削除の確認ダイアログをカスタムモーダルに置き換え

## 背景・目的

取引先削除時の確認ダイアログが `confirm()` (ブラウザ標準) を使用しており、アプリ内の他のアラート表示と見た目が統一されていない。`custom-alert-modal` を流用して「OK/キャンセル」の2択確認が行えるように拡張し、`confirm()` を完全に排除する。

---

## 変更対象ファイル

1. `src/index.html`
2. `src/js_core.html`
3. `src/js_account.html`

---

## 変更詳細

### 1. `src/index.html` — モーダルのボタン構成を拡張

**場所**: 以下の `<div style="text-align: right">` ブロック全体 (現在 line 1164〜1180 付近) を置き換える。

**変更前:**
```html
        <div style="text-align: right">
          <button
            id="alert-retry-btn"
            class="save-btn"
            onclick="closeAlert(); if(window._retryFn) window._retryFn();"
            style="padding: 8px 24px; display: none; margin-right: 8px; background: var(--teal);"
          >
            再試行
          </button>
          <button
            class="save-btn"
            onclick="closeAlert()"
            style="padding: 8px 24px"
          >
            OK
          </button>
        </div>
```

**変更後:**
```html
        <div style="text-align: right">
          <button
            id="alert-cancel-btn"
            class="save-btn"
            onclick="closeAlert()"
            style="padding: 8px 24px; display: none; margin-right: 8px; background: #6b7280;"
          >
            キャンセル
          </button>
          <button
            id="alert-retry-btn"
            class="save-btn"
            onclick="closeAlert(); if(window._retryFn) window._retryFn();"
            style="padding: 8px 24px; display: none; margin-right: 8px; background: var(--teal);"
          >
            再試行
          </button>
          <button
            id="alert-ok-btn"
            class="save-btn"
            onclick="closeAlert(); if(window._confirmFn) window._confirmFn();"
            style="padding: 8px 24px"
          >
            OK
          </button>
        </div>
```

**ポイント:**
- `id="alert-cancel-btn"` を新規追加（デフォルト `display: none`）
- OKボタンに `id="alert-ok-btn"` を付与
- OKボタンの `onclick` に `window._confirmFn` の呼び出しを追加

### 2. `src/js_core.html` — `closeAlert()` 更新 と `showConfirm()` 追加

#### 2-1. `closeAlert()` を更新する

**場所**: 現在 line 72〜78 の `closeAlert()` 関数全体を置き換える。

**変更前:**
```javascript
  function closeAlert() {
    const modal = $("custom-alert-modal");
    if (modal) modal.style.display = "none";
    const retryBtn = $("alert-retry-btn");
    if (retryBtn) retryBtn.style.display = "none";
    window._retryFn = null;
  }
```

**変更後:**
```javascript
  function closeAlert() {
    const modal = $("custom-alert-modal");
    if (modal) modal.style.display = "none";
    const retryBtn = $("alert-retry-btn");
    if (retryBtn) retryBtn.style.display = "none";
    const cancelBtn = $("alert-cancel-btn");
    if (cancelBtn) cancelBtn.style.display = "none";
    const okBtn = $("alert-ok-btn");
    if (okBtn) {
      okBtn.textContent = "OK";
      okBtn.style.background = "";
    }
    window._retryFn = null;
    window._confirmFn = null;
  }
```

#### 2-2. `showConfirm()` を追加する

**場所**: `closeAlert()` の直後（現在 line 79 付近）に以下の関数を挿入する。

```javascript
  function showConfirm(message, title, onConfirm) {
    window._confirmFn = onConfirm;
    const cancelBtn = $("alert-cancel-btn");
    if (cancelBtn) cancelBtn.style.display = "inline-block";
    const okBtn = $("alert-ok-btn");
    if (okBtn) {
      okBtn.textContent = "削除する";
      okBtn.style.background = "#DC2626";
    }
    showAlert(message, title, true);
  }
```

### 3. `src/js_account.html` — `confirm()` を `showConfirm()` に置き換え

**場所**: `handleDeleteAccount()` 内、現在 line 191〜215 付近。

**変更前:**
```javascript
    const msg = `【警告】取引先「${h.name}」を完全に削除しますか？\n\nこの取引先に紐づくすべての「部署」「案件状況」「活動ログ」が削除され、元に戻すことはできません。`;

    if (confirm(msg)) {
      showSaving();
      google.script.run
        .withSuccessHandler(() => {
          // メモリ上のデータも一括で削除
          db.accounts = db.accounts.filter((item) => item.id !== hId);
          db.departments = db.departments.filter(
            (item) => item.accountId !== hId,
          );
          db.projects = db.projects.filter((item) => item.accountId !== hId);
          db.logs = db.logs.filter((item) => item.accountId !== hId);

          if (t0HospId === hId) t0HospId = "";
          if (t1HospId === hId) t1HospId = "";

          updateAccountSelectOptions();

          showSuccess();
          changeAccount(3, "new");
        })
        .withFailureHandler((e) => showError(e, "取引先の削除に失敗しました"))
        .deleteAccountWithCascade(hId);
    }
```

**変更後:**
```javascript
    const msg = `取引先「${h.name}」を完全に削除しますか？\n\nこの取引先に紐づくすべての「部署」「案件状況」「活動ログ」が削除され、元に戻すことはできません。`;

    showConfirm(msg, "⚠️ 削除の確認", () => {
      showSaving();
      google.script.run
        .withSuccessHandler(() => {
          // メモリ上のデータも一括で削除
          db.accounts = db.accounts.filter((item) => item.id !== hId);
          db.departments = db.departments.filter(
            (item) => item.accountId !== hId,
          );
          db.projects = db.projects.filter((item) => item.accountId !== hId);
          db.logs = db.logs.filter((item) => item.accountId !== hId);

          if (t0HospId === hId) t0HospId = "";
          if (t1HospId === hId) t1HospId = "";

          updateAccountSelectOptions();

          showSuccess();
          changeAccount(3, "new");
        })
        .withFailureHandler((e) => showError(e, "取引先の削除に失敗しました"))
        .deleteAccountWithCascade(hId);
    });
```

**ポイント:**
- `if (confirm(msg)) { ... }` → `showConfirm(msg, title, () => { ... });` に変換
- メッセージ先頭の `【警告】` テキストは削除（タイトルで警告を表現するため）

---

## 完了条件 (Definition of Done)

1. `src/index.html` のモーダルにキャンセルボタン (`id="alert-cancel-btn"`) が追加されており、通常時は非表示である。
2. `src/js_core.html` に `showConfirm(message, title, onConfirm)` 関数が存在する。
3. `src/js_core.html` の `closeAlert()` が `_confirmFn`・キャンセルボタン・OKボタンの状態をリセットする。
4. `src/js_account.html` の `handleDeleteAccount()` 内に `confirm()` が存在しない。
5. 取引先削除ボタンを押すと「⚠️ 削除の確認」タイトルのカスタムモーダルが表示され、「削除する（赤）」と「キャンセル（グレー）」の2つのボタンが表示される。
6. 「削除する」押下で削除処理が実行され、「キャンセル」押下では何も起きない。
7. 通常の `showAlert()` と `showErrorWithRetry()` の挙動が変わっていないこと。

---

## 影響範囲

- 新規追加の `showConfirm()` は現時点で取引先削除にのみ使用するが、将来的に部署・案件の削除確認にも流用可能な汎用設計とする。
- `showAlert()` の既存シグネチャは変更しない。
- `_retryFn` の挙動に変更なし。
