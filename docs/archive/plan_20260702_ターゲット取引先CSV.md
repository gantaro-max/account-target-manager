# campaign_20260702_ターゲット取引先CSV

## 1. 背景・目的

admin/manager が現在ターゲットとして登録されている全取引先の一覧を手軽にCSV化できる機能を追加する。  
既存の「取引先別進捗レポート」とは異なり、案件データは含まず取引先マスタの基本情報のみをフラットなリストとして出力する。

---

## 2. 変更対象ファイル ＋ 機能要件

| ファイル | 変更内容 |
|---|---|
| `src/コード.js` | 新関数 `getAccountListCsv()` を追加 |
| `src/index.html` | tab4（取引先登録・編集）の control-bar にボタンを追加 |
| `src/js_log.html` | 新関数 `downloadAccountListCsv()` を追加 |

### `src/コード.js`

- 関数名: `getAccountListCsv()`
- 先頭で `_requireManager()` を呼び出し、admin/manager 以外はエラーを投げる
- `_getRows(SHEET.ACCOUNTS).map(_mapAccount)` で全取引先を取得（スコープ絞り込みなし）
- `_getRows(SHEET.USERS)` でユーザー一覧を取得し、`assignedUserId`（メールアドレス）→ `name` のマップを生成
- 優先度ラベルは `{ high: "高", mid: "中", low: "低" }` で日本語化する
- CSV ヘッダー（順序厳守）: `["担当者名", "取引先コード", "取引先名", "担当パートナー名", "優先度", "特記事項"]`
- 各行の値: `[userNameMap[h.assignedUserId] || "", h.code, h.name, h.partner, priorityLabel, h.note]`
- 行の並び順: 担当者名昇順 → 取引先名昇順（`localeCompare("ja")`）
- `_buildCsv(headers, rows)` を返す

### `src/index.html`

- tab4 の `.control-bar` 内、`#t3-partner-display` の `<span>` の直後に以下を追加:

```html
<button class="control-btn admin-only" style="display:none; margin-left:auto;" onclick="downloadAccountListCsv()">
  📋 ターゲット取引先CSV
</button>
```

- `admin-only` クラスにより、初期状態は非表示。ログイン後の権限初期化で admin/manager のみ表示される（既存の `js.html` の制御ロジックが自動適用）

### `src/js_log.html`

- 関数名: `downloadAccountListCsv()`
- 配置: `downloadAccountReportCsv` 関数の直後

**処理フロー**:

1. 確認ダイアログなし。即座に `Swal.fire({ title: "CSV出力中...", allowOutsideClick: false, didOpen: function() { Swal.showLoading(); } })` でローディング表示
2. `google.script.run.withSuccessHandler(...).withFailureHandler(...).getAccountListCsv()` を呼び出す

**`withSuccessHandler`**:
- `Swal.close()` でローディングを閉じる
- `csv` が空の場合: `Swal.fire("該当なし", "登録された取引先が見つかりませんでした。", "info")`
- ダウンロード処理:
  ```javascript
  var blob = new Blob([csv], { type: "text/csv;charset=utf-8;" });
  var url = URL.createObjectURL(blob);
  var a = document.createElement("a");
  a.href = url;
  a.download = "ターゲット取引先リスト_" + new Date().toISOString().slice(0, 10) + ".csv";
  document.body.appendChild(a);
  a.click();
  setTimeout(function() { document.body.removeChild(a); URL.revokeObjectURL(url); }, 100);
  ```

**`withFailureHandler`**:
- `Swal.fire("エラー", e.message, "error")`

## 3. UIフロー（操作シーケンス）

1. ユーザーが「🏥 取引先登録・編集」タブを開く（admin/manager のみタブが表示される）
2. control-bar 右端に「📋 ターゲット取引先CSV」ボタンが表示される
3. ボタンをクリック → 即座にローディング表示
4. GAS 処理完了 → ブラウザで `ターゲット取引先リスト_YYYY-MM-DD.csv` が自動ダウンロードされる
5. ダウンロード後、ローディングが自動的に閉じる

## 5. 注意事項・禁止事項

- **スコープ外変更禁止**: 既存の CSV エクスポート関数（`getCsvData`, `getProjectReport`, `getAccountReport`）は変更しない
- **`innerHTML` 禁止**: フロントエンドでのDOM操作は使用しない（本機能はDOMを動的生成しない）
- **Swal ダイアログ不要**: フィルター指定なし・即ダウンロードなので、選択ダイアログは設けない
- **全取引先対象**: `getAccountListCsv()` は admin/manager どちらも全取引先を出力する（`isAll` 分岐不要）
- **`_requireManager()` を必ず先頭で呼ぶ**: ロールチェックを省略しない
