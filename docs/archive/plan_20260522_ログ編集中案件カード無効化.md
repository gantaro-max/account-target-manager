# 実装指示書: ログ編集中の案件カード操作無効化

**作成日**: 2026-05-22  
**対象ブランチ**: feature/advance

---

## 背景・目的

活動ログの編集モード中（`editingLogId` が非null）に別の案件カードをクリックすると、
`log-proj-select` の値と案件フォームの内容が差し替わってしまう不具合がある。
保存時に意図しない案件のステージ・メモが上書きされる危険があるため修正する。

---

## 変更対象ファイル

- `src/js_log.html` のみ

---

## 実装内容

### 変更1: `renderActivities()` — 案件カードの描画ロジック修正

**場所**: `js_log.html` の `renderActivities()` 内、`cardAction` / `cardCursor` を定義している箇所（現行 409〜410行目付近）

**現行コード:**
```javascript
const cardAction = readOnly
  ? ""
  : ` onclick="$('log-proj-select').value='${p.id}'; loadProjectDataToForm();"`;
const cardCursor = readOnly ? "default" : "pointer";
```

**修正後コード:**
```javascript
const isEditingMode = !!editingLogId;
const cardAction = (readOnly || isEditingMode)
  ? ""
  : ` onclick="$('log-proj-select').value='${p.id}'; loadProjectDataToForm();"`;
const cardCursor = (readOnly || isEditingMode) ? "not-allowed" : "pointer";
const cardOpacity = isEditingMode ? "0.45" : "1";
```

そして同行の `<div class="project-card" style="...">` のインラインスタイルに `opacity: ${cardOpacity};` を追加する。

具体的には、現行の `return` 文中のプロジェクトカード `<div>` のスタイル属性を以下のように変更する:

```javascript
// 変更前（style属性の先頭部分）
`<div class="project-card" style="background-color: ${bgColor}; border-color: ${borderColor}; cursor: ${cardCursor}; transition: background-color 0.15s;"${cardAction} ...`

// 変更後
`<div class="project-card" style="background-color: ${bgColor}; border-color: ${borderColor}; cursor: ${cardCursor}; opacity: ${cardOpacity}; transition: background-color 0.15s, opacity 0.2s;"${cardAction} ...`
```

---

### 変更2: `editLog()` — 編集開始時にカードを再描画

**場所**: `editLog()` 関数の末尾（現行 `toggleActionButtons();` の直後）

**追加するコード:**
```javascript
renderActivities();
```

`editingLogId` をセットした後に `renderActivities()` を呼ぶことで、カードが薄く再描画される。
`renderActivities()` 内部では `$("log-proj-select").value` を保持したままセレクトを再構築するため、
直前に `editLog()` がセットしたプロジェクト選択は維持される。

---

### 変更3: `cancelEditLog()` — 編集キャンセル時にカードを再描画

**場所**: `cancelEditLog()` 関数の末尾（現行 `toggleActionButtons();` の直後）

**追加するコード:**
```javascript
renderActivities();
```

`editingLogId = null` にリセットした後に呼ぶことで、カードが通常の表示に戻る。

---

## UIフロー（完成後の挙動）

1. ユーザーがログをクリック → 編集モード開始
   - フォームタイトルが「✎ 過去のログを編集中」に変わる
   - **下部の全案件カードが `opacity: 0.45; cursor: not-allowed;` で薄く表示される**
   - **薄くなったカードはクリックしても何も起きない**
2. 「キャンセル」または「ログを更新」で編集モード終了
   - **全案件カードが通常表示（opacity: 1; cursor: pointer）に戻る**

## 完了条件 (Definition of Done)

- [ ] ログ編集中、案件カードが視覚的に薄く（opacity約0.45）表示される
- [ ] ログ編集中、案件カードにホバーしても色が変わらない（`not-allowed` カーソル）
- [ ] 「キャンセル」後、案件カードが通常表示に戻り、クリックで案件切り替えが再び機能する
- [ ] 「ログを更新」保存後、案件カードが通常表示に戻る
- [ ] `readOnly` モード（他担当者モード）では従来通り変化なし

## 注意事項

- `renderActivities()` は内部で `renderTimelineLogs()` と `toggleActionButtons()` を呼ぶため、
  `editLog()` 末尾の `toggleActionButtons()` は `renderActivities()` の呼び出しで代替される。
  ただし二重呼び出しになっても副作用はないため、既存の `toggleActionButtons()` 行は削除不要。
- `deleteLog()` 内では既に `cancelEditLog()` → `renderActivities()` が呼ばれているため、追加変更不要。
