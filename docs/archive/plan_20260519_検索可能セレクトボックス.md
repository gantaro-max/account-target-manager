# 実装指示書: 取引先選択プルダウンを検索可能セレクトボックスに置き換え (Tom Select)

## 背景・目的

取引先数が増加した際に、標準 `<select>` では目的の取引先を探しにくくなる。  
`Tom Select 2.x`（jQuery不要・軽量）をCDN経由で導入し、Tab0・Tab1・Tab3の取引先選択プルダウンをキーワード検索できるコンボボックスに置き換える。

**設計の重点2点:**
1. **XSS対策**: Tom Selectの `render` コールバック内では必ず引数の `escape()` 関数を使用する
2. **パフォーマンス**: 全データはメモリ上に存在するため非同期通信・デバウンスは不要。`maxOptions: null` で全件表示する

### 3. `src/js_account.html` — `updateAccountSelectOptions()` と `changeAccount()` の更新

#### 3-1. ファイル先頭にインスタンス管理変数を追加する

**場所**: `<script>` タグの直後（ファイル先頭の `// js_account.html — 取引先管理` コメント行の直前）に追加する。

```javascript
  const _tsInstances = {}; // Tom Select インスタンス管理 (key: 't0'|'t1'|'t3')
```

#### 3-2. `updateAccountSelectOptions()` 全体を置き換える

**変更前** (現在 line 4〜27 付近の関数全体):
```javascript
  function updateAccountSelectOptions() {
    const optsNoNew = db.accounts
      .map((h) => `<option value="${h.id}">${h.name}</option>`)
      .join("");

    const newOpt = `<option value="new" style="color:var(--teal); font-weight:bold;">＋ 新規取引先を登録</option>`;

    if ($("t3-account")) $("t3-account").innerHTML = optsNoNew + newOpt;
    if ($("t0-account")) {
      $("t0-account").innerHTML =
        `<option value="">-- 対象取引先を選択 --</option>` + optsNoNew + newOpt;
      if (t0HospId && t0HospId !== "new") $("t0-account").value = t0HospId;
    }

    if ($("t1-account")) $("t1-account").innerHTML = optsNoNew;

    if (!t1HospId && db.accounts.length > 0) t1HospId = db.accounts[0].id;

    if ($("t0-account")) $("t0-account").value = t0HospId || "";
    if ($("t1-account")) $("t1-account").value = t1HospId;
    if ($("t3-account")) $("t3-account").value = t3HospId;

    loadProjectDataToForm();
  }
```

**変更後:**
```javascript
  function _buildHospOpts(includeNew) {
    const opts = db.accounts.map((h) => ({ value: h.id, text: h.name }));
    if (includeNew) opts.push({ value: "new", text: "＋ 新規取引先を登録", isNew: true });
    return opts;
  }

  function _getOrInitTS(key, elId, config) {
    if (_tsInstances[key]) return _tsInstances[key];
    const el = $(elId);
    if (!el) return null;
    _tsInstances[key] = new TomSelect(el, config);
    return _tsInstances[key];
  }

  function _refreshTS(key, opts, value) {
    const ts = _tsInstances[key];
    if (!ts) return;
    ts.clearOptions();
    ts.addOptions(opts);
    ts.setValue(value, true); // silent=true: onChange を発火させない
  }

  const _tsRender = {
    option: function (data, escape) {
      if (data.isNew) {
        return `<div style="color:var(--teal);font-weight:bold;">${escape(data.text)}</div>`;
      }
      return `<div>${escape(data.text)}</div>`;
    },
    item: function (data, escape) {
      if (data.isNew) {
        return `<span style="color:var(--teal);font-weight:bold;">${escape(data.text)}</span>`;
      }
      return `<span>${escape(data.text)}</span>`;
    },
  };

  function updateAccountSelectOptions() {
    // Tab0: 空選択あり + 新規登録
    _getOrInitTS("t0", "t0-account", {
      valueField: "value",
      labelField: "text",
      searchField: ["text"],
      maxOptions: null,
      placeholder: "-- 対象取引先を選択 --",
      render: _tsRender,
      onChange: (val) => handleT0AccountChange(val),
    });
    _refreshTS("t0", _buildHospOpts(true), t0HospId || "");

    // Tab1: 取引先一覧のみ（新規登録なし）
    if (!t1HospId && db.accounts.length > 0) t1HospId = db.accounts[0].id;
    _getOrInitTS("t1", "t1-account", {
      valueField: "value",
      labelField: "text",
      searchField: ["text"],
      maxOptions: null,
      render: _tsRender,
      onChange: (val) => changeAccount(1, val),
    });
    _refreshTS("t1", _buildHospOpts(false), t1HospId || "");

    // Tab3: 新規登録あり
    _getOrInitTS("t3", "t3-account", {
      valueField: "value",
      labelField: "text",
      searchField: ["text"],
      maxOptions: null,
      render: _tsRender,
      onChange: (val) => changeAccount(3, val),
    });
    _refreshTS("t3", _buildHospOpts(true), t3HospId || "new");

    loadProjectDataToForm();
  }
```

**場所**: 現在の `changeAccount()` 関数内の先頭3行（`t0HospId`/`t1HospId`/`t3HospId` を更新している箇所）の直後に追加する。

**変更前の該当箇所:**

## 補足・注意事項

- **`_tsInstances` の初期化タイミング**: `updateAccountSelectOptions()` が初回呼ばれたときにインスタンスを生成する（`_getOrInitTS` が2回目以降はスキップ）。DOMが存在する状態で呼ばれるため問題なし。
- **`ts.setValue(value, true)` の `true`**: 第2引数は `silent`フラグ。`onChange` が再発火しないためループしない。
- **Tom Select がラップした後の `<select>`**: Tom Select が `<select>` を隠して独自UIを表示する。`$("t0-account").innerHTML` や `.value` の直接操作は動作しなくなるため、必ず `_tsInstances` 経由で操作すること。
- **`ref-hosp`・`qa-ref-hosp`**: クイック登録モーダル内の別セレクトは今回の対象外。Tom Select化は不要。
