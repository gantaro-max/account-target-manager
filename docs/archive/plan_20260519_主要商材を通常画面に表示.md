## 3. 実装詳細

### 3.1 進行中案件カード（`src/js.html` 225行付近）

案件名 `${p.name}` の直後に `targetProduct` を追加する。

```javascript
// 変更前
<div style="font-weight:bold; font-size:13px; color:var(--navy);">${p.name}</div>

// 変更後
<div style="font-weight:bold; font-size:13px; color:var(--navy);">${p.name}${p.targetProduct ? `<span style="font-size:11px; color:var(--muted); font-weight:normal; margin-left:6px;">(${p.targetProduct})</span>` : ""}</div>
```

### 3.2 活動ログ一覧（`src/js_log.html` 272行付近）

`[${dName}] ${p?.name}` の直後に `targetProduct` を追加する。

```javascript
// 変更前
<div style="font-weight:600; color:var(--navy); margin-bottom:4px;">[${dName}] ${p?.name}</div>

// 変更後
<div style="font-weight:600; color:var(--navy); margin-bottom:4px;">[${dName}] ${p?.name}${p?.targetProduct ? `<span style="font-size:11px; color:var(--muted); font-weight:normal; margin-left:6px;">(${p.targetProduct})</span>` : ""}</div>
```

### 3.3 案件カード・活動ログタブ（`src/js_log.html` 395行付近）

`<strong>` タグの案件名の直後に `targetProduct` を追加する。

```javascript
// 変更前
<strong style="font-size:15px; margin-left:6px; color:var(--navy);">${p.name}</strong>${keymanStr}

// 変更後
<strong style="font-size:15px; margin-left:6px; color:var(--navy);">${p.name}</strong>${p.targetProduct ? `<span style="font-size:11px; color:var(--muted); font-weight:normal; margin-left:6px;">(${p.targetProduct})</span>` : ""}${keymanStr}
```

---

## 4. 注意事項

- `targetProduct` が空・未設定の場合は何も表示しない（`|| ""` で空文字にしない）。
- テンプレートリテラルが入れ子になるため、クォートのエスケープに注意すること。
- 既存のレイアウト・クリックイベントは変更しないこと。
