# 実装指示書：案件ステージ変更履歴（D）

作成日: 2026-05-20  
機能分類: TASKS.md 優先度低 - 案件ステージ変更履歴

---

## 概要

案件 (project) のステージ変更を記録し、一覧表示できる監査機能を追加する。

- **記録タイミング**: `saveProject`（初期ステージ）/ `updateProject`（手動保存）/ `syncMyData`（バルク同期）
- **表示**: 案件カードの「📋 履歴」ボタン → SweetAlert2 モーダル（テーブル形式）
- **データ**: 新規シート `stage_history`（変更日時・ステージ・変更者）

---

## 事前作業（スプレッドシート）— 実装前に必ず実施

スプレッドシートを開き、**`stage_history` という名前のシート**を手動で新規追加する。  
1行目（ヘッダー行）に以下を入力する（半角・全角スペースなし）：

```
A: id  B: project_id  C: account_id  D: stage  E: changed_at  F: changed_by
```

### 1-7. `getStageHistory(projectId)` 関数を追加

`deleteAccountWithCascade` の `return { ok: true }; }` の直後（line 779付近）に追加する。

```javascript
function getStageHistory(projectId) {
  const tz = Session.getScriptTimeZone();
  return _getRows(SHEET.STAGE_HISTORY)
    .filter((r) => String(r.project_id) === String(projectId))
    .map((r) => ({
      stage: String(r.stage || "0"),
      changedAt: r.changed_at
        ? Utilities.formatDate(new Date(r.changed_at), tz, "yyyy-MM-dd HH:mm")
        : "",
      changedBy: String(r.changed_by || ""),
    }))
    .sort((a, b) => a.changedAt.localeCompare(b.changedAt));
}
```

### 2-2. `openStageHistory(projectId)` 関数を追加

`</script>` の直前に以下の関数を追加する。

```javascript
function openStageHistory(projectId) {
  const p = db.projects.find(function (proj) { return proj.id === projectId; });
  const projName = p ? p.name : "";
  Swal.fire({
    title: projName,
    html: '<div id="sh-content" style="text-align:center;padding:20px;color:var(--gray);">読み込み中...</div>',
    width: 520,
    showConfirmButton: false,
    showCloseButton: true,
  });
  google.script.run
    .withSuccessHandler(function (history) {
      const el = document.getElementById("sh-content");
      if (!el) return;
      if (!history || history.length === 0) {
        el.innerHTML = '<div style="padding:20px;color:var(--gray);">変更履歴はありません。</div>';
        return;
      }
      el.innerHTML =
        '<table style="width:100%;border-collapse:collapse;text-align:left;">'
        + '<thead><tr style="background:#f8fafc;">'
        + '<th style="padding:6px 8px;font-size:11px;color:var(--gray);border-bottom:2px solid #e2e8f0;">変更日時</th>'
        + '<th style="padding:6px 8px;font-size:11px;color:var(--gray);border-bottom:2px solid #e2e8f0;">ステージ</th>'
        + '<th style="padding:6px 8px;font-size:11px;color:var(--gray);border-bottom:2px solid #e2e8f0;">変更者</th>'
        + '</tr></thead><tbody>'
        + history.map(function (h) {
            return '<tr>'
              + '<td style="padding:6px 8px;font-size:12px;border-bottom:1px solid #f0f0f0;">' + h.changedAt + '</td>'
              + '<td style="padding:6px 8px;font-size:12px;border-bottom:1px solid #f0f0f0;"><span class="stage stage-' + h.stage + '">' + (STAGE_LABELS[parseInt(h.stage, 10)] || h.stage) + '</span></td>'
              + '<td style="padding:6px 8px;font-size:12px;border-bottom:1px solid #f0f0f0;color:var(--gray);">' + h.changedBy + '</td>'
              + '</tr>';
          }).join('')
        + '</tbody></table>';
    })
    .withFailureHandler(function () {
      const el = document.getElementById("sh-content");
      if (el) el.innerHTML = '<div style="padding:20px;color:var(--red);">取得に失敗しました。</div>';
    })
    .getStageHistory(projectId);
}
```

## 注意事項

- `syncMyData` での差分検出は `oldStage === undefined`（新規案件）をスキップすること。`saveProject()` が初期エントリを書くため、sync 側での重複追記を防ぐ。
- カードのクリックイベントと履歴ボタンの競合を防ぐため、`event.stopPropagation()` は必須。
- `STAGE_LABELS` は `js_core.html` でグローバル定義済みのため、`js_log.html` から参照可能。
