## 3. 実装詳細

### 3.1 `getActivePlans()` に `item` を追加（`src/コード_v2_9.js`）

`idxDesc` の次行に `idxItem` を追加し、`result.push` にも含める。

```javascript
// 変更前
const idxDesc      = headers.indexOf('description');

// 変更後
const idxDesc      = headers.indexOf('description');
const idxItem      = headers.indexOf('item');
```

```javascript
// 変更前
result.push({
  name:        String(row[idxName]),
  description: idxDesc >= 0 ? String(row[idxDesc] || '') : ''
});

// 変更後
result.push({
  name:        String(row[idxName]),
  description: idxDesc >= 0 ? String(row[idxDesc] || '') : '',
  item:        idxItem >= 0 ? String(row[idxItem] || '') : ''
});
```

### 3.2 `openQuickAddModal()` で datalist を更新（`src/js_quick_add.html`）

モーダルを表示する直前（`$("quick-add-modal").style.display = "flex"` の行）の前に
`populateCampaignDatalist()` の呼び出しを追加する。

```javascript
// 変更前
    $("quick-add-modal").style.display = "flex";
  }

// 変更後
    if (typeof populateCampaignDatalist === "function") populateCampaignDatalist();
    $("quick-add-modal").style.display = "flex";
  }
```

### 3.3 `index.html` の案件名フィールド変更（`src/index.html`）

#### (A) 取引先登録・編集タブ（`id="new-proj-name"`）

プレースホルダーのみ変更。

```html
<!-- 変更前 -->
placeholder="キャンペーンを選択または入力"

<!-- 変更後 -->
placeholder="案件を入力"
```

#### (B) 連鎖モーダル（`id="qa-proj-name"`）

`list` 属性・`autocomplete` 属性を追加し、プレースホルダーを変更。
`<datalist>` タグは既存の `campaign-datalist`（取引先登録タブ側に存在）をそのまま共用できるため、新規追加不要。

```html
<!-- 変更前 -->
<input
  type="text"
  id="qa-proj-name"
  placeholder="例：電子カルテ更新"
/>

<!-- 変更後 -->
<input
  type="text"
  id="qa-proj-name"
  list="campaign-datalist"
  placeholder="案件を入力"
  autocomplete="off"
/>
```

## 4. 注意事項

- `<datalist id="campaign-datalist">` は `src/index.html` 内に1つだけ存在する。HTML仕様上、複数の `<input>` が同一 `datalist` を参照することは正当であり、新規追加は不要。
- `populateCampaignDatalist()` は `js_project.html` で定義されているため、`typeof` ガードを付けて呼び出すこと（ロード順の安全策）。
- `item` カラムは現時点では参照のみ（対象製品フィールドへの自動入力は今回スコープ外）。
