# 実装指示書: サマリータブ 案件リストのカードUI化

## 背景・目的

全体サマリー（Tab2）の「全取引先 案件の状況とネクストアクション」欄（`summary-integrated-list`）は、
現在インラインスタイルの `<div>` で描画されており、視認性が低い。

`project-card` クラス（Tab0で既に使用済み）を適用し、
**取引先の優先度（高/中/低）に応じた左ボーダーアクセント**を加えてカードUIに変換する。  
これにより「期限超過（赤背景）」と「優先度（左ボーダー色）」という2つの視覚信号が干渉なく共存できる。

---

## 変更対象ファイル

1. `src/js_review.html` — `renderSummary()` 内の `summary-integrated-list` レンダリング部分のみ

**変更なし**: `src/css.html`・`src/index.html`・その他ファイル  
（`.project-card` は既存クラスがそのまま使える）

## 変更の設計意図

### 色の使い分け（干渉しない設計）

| 視覚信号 | 表現方法 | 値 |
|---|---|---|
| 期限超過 | カード背景色 | `#FEF2F2`（薄い赤） |
| 取引先優先度：高 | 左ボーダー 4px | `#DC2626`（赤） |
| 取引先優先度：中 | 左ボーダー 4px | `#D97706`（アンバー） |
| 取引先優先度：低/未設定 | 左ボーダー 4px | `#CBD5E1`（スレートグレー） |
| ステージ | `stage-N` バッジ | 既存のバッジ色 |

- 期限超過の「赤背景」と優先度高の「赤左ボーダー」は視覚的に共存可能（背景 vs. ボーダー）
- 左ボーダー 4px は `.project-card` の `border: 1px solid var(--border)` の左辺を上書きする  
  （インラインスタイルがクラスに優先するため、右・上・下は 1px のままになる）

### ホバー効果

`onmouseover` / `onmouseout` で `backgroundColor` のみを変化させる。  
Tab0の案件カード（`js_log.html`）・活動ログ一覧（`log-item`）と同じ実装方式で統一。

## 完了条件 (Definition of Done)

1. `summary-integrated-list` の各案件が `project-card` クラスの角丸カード形式で表示される。
2. 各カードの左ボーダーが取引先の優先度に応じた色（高=赤/中=アンバー/低=グレー）で表示される。
3. 期限超過の案件は引き続き薄い赤背景（`#FEF2F2`）で強調表示される。
4. カードをホバーすると背景色が変化する。
5. 案件名・取引先名/部署名・ステージバッジ・ネクストアクション・期限の表示内容が変更前と同一である。
6. `src/js_review.html` の `node --check` が通る。
7. 変更は `src/js_review.html` の 1 ファイルのみ。

## 補足・注意事項

- `h?.priority` の値は取引先マスターに登録された文字列（`"高"` / `"中"` / `"低"`）をそのまま参照する。  
  未登録または空文字の場合は `#CBD5E1`（グレー）にフォールバックする。
- `border-left: 4px solid ${priorityBorderColor}` はインラインスタイルで指定するため、CSS クラスの追加は不要。
- `.project-card` の既存スタイル（`border-radius: 8px; padding: 14px; margin-bottom: 12px;`）はそのまま適用される。  
  変更前の `padding:10px; border-radius:4px; margin-bottom:8px;` インラインスタイルは削除されることに注意。
