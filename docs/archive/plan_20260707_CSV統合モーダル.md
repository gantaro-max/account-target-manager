# campaign_20260707_CSV統合モーダル

## 1. 背景・目的

Tab 0 ツールバーに分散している「My活動ログ CSV」「My案件 CSV」「取引先別進捗レポート」の 3 ボタンを廃止し、1 つの「📊 データCSV出力」ボタン＋モーダルに統合する。

出力フォーマットは **1種類に統一（16列）**。案件情報を左側に、ログ情報を右側に横展開した全部盛り形式とする。取引先・案件・期間の3フィルターを組み合わせてデータを絞り込む。Excel でのピボット・フィルター・集計に汎用的に使えることを設計目標とする。

「案件別進捗レポート（全体）」ボタン（`downloadProjectReportCsv`）は**統合対象外**。変更しないこと。

---

## 2. 出力フォーマット仕様

### 列構成（16列固定）

| # | 列名 | データソース |
|---|---|---|
| 1 | 担当者名 | accounts.assigned_user_id → users.name |
| 2 | 取引先名 | accounts.name |
| 3 | 部署名 | departments.name（projects.department_id 経由） |
| 4 | 案件名 | projects.name |
| 5 | 対象製品 | projects.target_product |
| 6 | 進捗ステージ | projects.current_stage（ラベル変換） |
| 7 | 受注/失注 | projects.closing_status |
| 8 | 最新課題メモ | projects.latest_note |
| 9 | ネクストアクション | projects.next_action_text |
| 10 | アクション担当者 | projects.next_action_assignee |
| 11 | 次回予定日 | projects.next_action_date |
| 12 | 訪問日 | logs.visit_date |
| 13 | 活動内容 | logs.content |
| 14 | 同行者 | logs.accompanied_by |
| 15 | 添付URL | logs.estimate_url |
| 16 | 更新日時 | logs.updated_at |

### 行の生成ルール

```
スコープ内の各案件に対して：
  period フィルターに合致するログ = filtered_logs（訪問日降順）
  if filtered_logs が空:
    → 案件情報のみ1行出力（列12〜16は空文字）
  else:
    → filtered_logs の各ログにつき1行出力（列1〜11は各行に繰り返し）
```

- 「スコープ内の案件」は 取引先フィルター + 案件フィルター で決まる
- 「期間フィルター」はログ行の絞り込みにのみ使用し、案件自体の出・不出には影響しない
- 直近1ヶ月 = 今日から30日前〜今日

### src/コード.js

既存の `getCsvData()` / `getAccountReport()` は**削除しないこと**（呼び出し元がなくなるだけ）。

`getAccountListCsv()` の直後（ファイル末尾付近）に以下の関数を追加：

```javascript
function getUnifiedCsv(params) {
  var me    = _requireRegisteredUser();
  var email = String(me.user_id || Session.getActiveUser().getEmail() || "").trim();
  var role  = me.role || _getMyRole();
  var isAll = role === "admin" || role === "manager";
  var tz    = Session.getScriptTimeZone();

  var accountId = params.accountId; // 'all' | account.id
  var projectId  = params.projectId;  // 'all' | project.id
  var dateMode   = params.dateMode;   // 'all' | 'recent' | 'range'
  var dateFrom   = params.dateFrom;   // ISO string | null
  var dateTo     = params.dateTo;     // ISO string | null

  var accounts   = _getRows(SHEET.ACCOUNTS);
  var departments = _getRows(SHEET.DEPARTMENTS);
  var projects    = _getRows(SHEET.PROJECTS);
  var logs        = _getRows(SHEET.LOGS);
  var users       = _getRows(SHEET.USERS);

  // ユーザー名マップ
  var userNameMap = {};
  users.forEach(function (u) { userNameMap[u.user_id] = u.name || u.user_id; });

  // 取引先マップ
  var hospMap = {};
  accounts.forEach(function (h) { hospMap[h.id] = h; });

  // 部署マップ
  var deptMap = {};
  departments.forEach(function (d) { deptMap[d.id] = d.name; });

  // ロールによるスコープ（admin/manager=全件、その他=自担当）
  var scopedAccountIds = new Set();
  accounts.forEach(function (h) {
    if (isAll || String(h.assigned_user_id || "").trim() === email) {
      scopedAccountIds.add(h.id);
    }
  });
  // 取引先フィルター適用
  if (accountId !== "all") {
    scopedAccountIds = new Set(
      Array.from(scopedAccountIds).filter(function (id) { return id === accountId; })
    );
  }
  if (scopedAccountIds.size === 0) return null;

  // 案件フィルター適用
  var scopedProjects = projects.filter(function (p) {
    if (!scopedAccountIds.has(p.account_id)) return false;
    if (projectId !== "all" && p.id !== projectId) return false;
    return true;
  });
  if (scopedProjects.length === 0) return null;

  // 進捗ステージラベル
  var STAGE_LABELS = ["0：未接触","1：初回訪問済","2：ニーズ確認中","3：提案実施中","4：クロージング"];

  // 日付フォーマットヘルパー
  function fmt(value, format) {
    if (!value) return "";
    var d = (value instanceof Date) ? value : new Date(value);
    if (isNaN(d.getTime())) return "";
    return Utilities.formatDate(d, tz, format || "yyyy/MM/dd");
  }

  // 期間フィルター判定
  var recentCutoff = null;
  if (dateMode === "recent") {
    recentCutoff = new Date();
    recentCutoff.setDate(recentCutoff.getDate() - 30);
  }
  var rangeFrom = (dateMode === "range" && dateFrom) ? new Date(dateFrom) : null;
  var rangeTo   = null;
  if (dateMode === "range" && dateTo) {
    rangeTo = new Date(dateTo);
    rangeTo.setHours(23, 59, 59, 999);
  }

  function passDateFilter(visitDate) {
    if (dateMode === "all") return true;
    var d = visitDate ? new Date(visitDate) : null;
    if (!d || isNaN(d.getTime())) return false;
    if (dateMode === "recent") return d >= recentCutoff;
    if (dateMode === "range") {
      if (rangeFrom && d < rangeFrom) return false;
      if (rangeTo   && d > rangeTo)   return false;
      return true;
    }
    return true;
  }

  // 案件ごとのログをマップ化（project_id → ログ配列）
  var logsByProject = {};
  logs.forEach(function (l) {
    if (!l.project_id) return;
    if (!logsByProject[l.project_id]) logsByProject[l.project_id] = [];
    logsByProject[l.project_id].push(l);
  });

  // 行生成
  var headers = [
    "担当者名","取引先名","部署名","案件名",
    "対象製品","進捗ステージ","受注/失注",
    "最新課題メモ","ネクストアクション","アクション担当者","次回予定日",
    "訪問日","活動内容","同行者","添付URL","更新日時"
  ];
  var rows = [];

  scopedProjects.forEach(function (p) {
    var hosp    = hospMap[p.account_id] || {};
    var stageNum = parseInt(p.current_stage, 10) || 0;
    var projCols = [
      userNameMap[hosp.assigned_user_id] || hosp.assigned_user_id || "",
      hosp.name || "",
      deptMap[p.department_id] || "",
      p.name || "",
      p.target_product || "",
      STAGE_LABELS[stageNum] || String(stageNum),
      p.closing_status || "",
      p.latest_note || "",
      p.next_action_text || "",
      p.next_action_assignee || "",
      p.next_action_date || "",
    ];

    // 期間フィルターに合致するログを訪問日降順で取得
    var filteredLogs = (logsByProject[p.id] || [])
      .filter(function (l) { return passDateFilter(l.visit_date); })
      .sort(function (a, b) {
        return new Date(b.visit_date) - new Date(a.visit_date);
      });

    if (filteredLogs.length === 0) {
      // ログなし or 期間外ログのみ → 案件情報だけ1行（ログ列は空）
      rows.push(projCols.concat(["","","","",""]));
    } else {
      filteredLogs.forEach(function (l) {
        rows.push(projCols.concat([
          fmt(l.visit_date),
          l.content || "",
          l.accompanied_by || "",
          l.estimate_url || "",
          fmt(l.updated_at, "yyyy-MM-dd HH:mm"),
        ]));
      });
    }
  });

  if (rows.length === 0) return null;
  return _buildCsv(headers, rows);
}
```

## 4. UIフロー（操作シーケンス）

1. Tab 0 ツールバーの「📊 データCSV出力」ボタンをクリック
2. モーダルが開く（フィルター3セクション）
3. ① 取引先を選択（全取引先 or 特定取引先）
4. ② 案件名を入力で絞り込み、セレクトから選択（任意）
5. ③ 期間を選択（全件 / 直近1ヶ月 / 期間指定）
   - 「期間指定」選択時のみ日付入力欄が表示される
6. 「📥 CSV出力」クリック → バリデーション → ローディング
7. GAS `getUnifiedCsv(params)` 呼び出し → 16列CSV ダウンロード

## 6. 注意事項・禁止事項

- `downloadProjectReportCsv()` と `getProjectReport()` は**一切変更しないこと**

- `getUnifiedCsv` 内の取引先スコープ制御（admin/manager=全件、その他=自担当）は**必ず維持すること**
- 期間フィルターは**ログ行の絞り込みのみ**に使用し、案件の出・不出には影響させないこと
