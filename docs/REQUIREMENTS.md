# 取引先ターゲット管理アプリ - 要件定義書

## 1. 機能要件 (Functional Requirements)

### 1.1 ターゲット・マスタ管理

- **取引先管理**: 取引先名、所在地、優先度、担当MS、導入機器等の情報を管理。
- **階層構造**: 「取引先 ＞ 部署 ＞ 案件 ＞ 活動ログ」のリレーションシップを維持したデータ管理。
- **マスター参照**: 既存の取引先マスター（スプレッドシート）から情報を検索し、新規登録時に自動補完する機能。
- **重複チェック**: 取引先名または固有の取引先コードによる二重登録の防止。

### 1.2 営業活動・プロジェクト管理

- **案件ステージ管理**: ステージ 0（未接触）から ステージ 4（クロージング）までの5段階による進捗管理。
- **ネクストアクション**: 次回のアクション予定日、内容、担当者を設定し、期限超過時に視覚的なアラートを表示。
- **活動ログ記録**: 訪問日、同行者、詳細内容を記録。
- **資料添付**: 見積書等のファイルをGoogleドライブへアップロードし、ログにリンクを紐付け。

### 1.3 レビュー・分析

- **KPI集計**: 月次の接点部署数、同行回数、提案中案件数（Stage 3以上）の自動算出。
- **月次セルフチェック**: 担当者が設定された設問に対して月次で回答を行う機能。
- **管理者フィードバック**: 管理者が担当者の活動を評価し、コメントを入力する機能。

### 1.5 キャンペーンマスター機能 (新規追加: 2026-05-18)

- **キャンペーンマスター管理**: 年間を通じた重点取組（キャンペーン）を管理者がスプレッドシートで直接管理する。アプリ側は読み取り専用。
- **キャンペーンの期間管理**: 各キャンペーンに開始日・終了日を設定し、今日の日付が範囲内にある「期間中のキャンペーン」のみをアプリ上の選択リストに表示する。
- **案件へのキャンペーン紐付け**: 案件に対してキャンペーンを1つ紐付ける（任意）。案件1件につきキャンペーンは単一選択。
- **ハイブリッドUI**: 案件フォームのキャンペーンフィールドはコンボボックス形式とし、リストから選択することも自由テキスト入力することも可能とする。リストにないキャンペーン名を直接入力できる柔軟性を持たせる。

### 1.6 通知・フィルター機能 (追加: 2026-05-19)

- **期限超過メールリマインダー**: GASの時間ドリブントリガー（毎日・午前8時台）で`sendOverdueReminders()`を実行し、`nextActionDate`が当日以前の案件を担当者へメール通知する。送信者表示名は「取引先ターゲット管理システム」。
- **取引先名フィルター**: サマリータブの案件一覧に取引先名フリーワード検索フィールドを追加。ステージフィルターとのAND条件で絞り込み可能。

### 1.10 ターゲット取引先CSV出力 (実装済み: 2026-07-02)

- **ターゲット取引先CSV**: `admin`/`manager` が現在ターゲットとして登録している全取引先の基本情報を CSV 出力する。
- **ボタン位置**: グローバルヘッダー（クラウド同期ボタン隣）。`admin-only` クラスにより `admin`/`manager` のみ表示。
- **出力列（6列）**: 担当者名 / 取引先コード / 取引先名 / 担当パートナー名 / 優先度（高/中/低） / 特記事項
- **行の並び順**: 担当者名 → 取引先名 の昇順。
- **バックエンド保護**: `_requireManager()` による二重防御。

### 1.11 CSVエクスポート統合モーダル (実装済み: 2026-07-07)

- **統合モーダル**: Tab 0 の旧3ボタン（My活動ログ CSV・My案件 CSV・取引先別進捗レポート）を廃止し、「📊 データCSV出力」ボタン1本に統合。
- **フィルター**: ① 取引先（全取引先 or 特定取引先）/ ② 案件（テキスト部分一致絞り込み＋セレクト）/ ③ 期間（全件 / 直近1ヶ月 / 期間指定）の3フィルターを組み合わせ可能。
- **出力フォーマット（18列）**: 担当者名・取引先コード・取引先名・担当MS・部署名・案件名・対象製品・進捗ステージ・受注/失注・最新課題メモ・ネクストアクション・アクション担当者・次回予定日・訪問日・活動内容・同行者・添付URL・更新日時
- **行生成ルール**: 期間フィルターはログ行のみ絞り込む。スコープ内の案件は必ず出力（ログなし/期間外のみの案件は案件情報1行＋ログ列空）。ログがある案件は1行1ログで展開し案件情報を繰り返し。
- **権限スコープ**: `admin`/`manager` は全取引先、`leader`/`member` は自担当取引先のみ。
- **統合対象外**: 「📊 案件別進捗レポート（全体）」ボタンは別機能として残置。

### 1.8 統計・可視化機能 (実装済み: 2026-05-20〜21)

- **統計タブ**: 「📈 統計」タブを追加。Chart.js v4 によるグラフで営業状況を可視化する。
- **グラフビュー切替**: 「案件概況」（ステージ別・受注失注ドーナツ）と「活動状況」（月別活動件数棒グラフ・担当者別案件数横棒グラフ）の2タブで切り替え。1画面に2グラフを表示。
- **担当者別案件数グラフ**: `admin`/`manager` ロールのみ表示。「全体」選択時のみ表示し、個人フィルタ選択時は非表示。
- **担当者フィルタ**: `admin`/`manager` が担当者セレクトで個人を選択すると、全統計データがその担当者に絞り込まれる。
- **初回ロードキャッシュ**: 初回クリック時のみ GAS を呼び出し、以降はメモリキャッシュから描画。担当者切り替え時はリロード。

### 1.9 他担当者取引先参照機能 (実装済み: 2026-05-20)

- **他担当者閲覧**: `member`/`leader` ロールが、他の担当者が登録した取引先を閲覧専用で参照できる。📝 活動＆アクション・🔭 取引先ダッシュボードタブに担当者セレクターを追加。
- **閲覧専用制御**: 他担当者の取引先はログ入力フォーム・編集操作が非表示となり、閲覧のみ可能。Upsert 同期スコープは自分の担当取引先のみを維持。
- **バックグラウンドプリフェッチ**: 担当者選択時に全取引先詳細を `getAccountDetailBulk()` で一括取得・キャッシュ。再選択時はGAS呼び出しなしで即時描画。失敗時は個別フェッチにフォールバック。

### 1.7 Googleカレンダー連携 (実装済み・一時無効化: 2026-05-19)

- 案件の「次回アクション日」をGoogleカレンダーに自動同期する機能をGAS側に実装済み（`_syncCalendarEvent()`）。
- `appsscript.json`に`https://www.googleapis.com/auth/calendar`スコープを追加済み。
- 現在は`executeAs: USER_DEPLOYING`の制約（全イベントがオーナーカレンダーに集約される）のため一時無効化中。再有効化は`_syncCalendarEvent()`の早期returnを削除するだけで可能。

### 1.4 ユーザビリティ

- **クイック登録ウィザード**: 取引先、部署、案件を1つのフローで連続して登録できるUI。
- **クラウド同期**: フロントエンド（メモリ）での操作内容を一括でバックエンド（スプレッドシート）へ反映。
- **CSVエクスポート**: 「📊 データCSV出力」ボタン（Tab 0）のモーダルから、取引先・案件・期間の3フィルターを指定して18列統一フォーマットのCSVをダウンロードできる。`member`/`leader` は自担当分のみ、`manager`/`admin` は全担当者分を出力。BOM付きUTF-8 形式のため Excel で文字化けなし。
- **ターゲット取引先CSV**: ヘッダーの「📋 ターゲット取引先CSV」ボタンで、登録中の全対象取引先の基本情報（6列）を即時ダウンロード。`admin`/`manager` のみ表示。

## 2. 非機能要件 (Non-Functional Requirements)

### 2.1 権限・セキュリティ

- **ロールベースアクセス制御 (RBAC)**: 以下の4段階制御。認証はGoogleアカウントを利用。

| ロール | 表示名 | 主な権限 |
| :----- | :----- | :------- |
| `admin` | 管理者 | 全権限。全ユーザーデータの閲覧・編集、取引先削除、設問管理。 |
| `manager` | 責任者 | 全取引先の閲覧（読み取り専用）。設問管理・月次評価コメントの編集可。活動ログ入力・取引先登録編集・クラウド同期は不可。サマリーはleader/memberのみ選択可。 |
| `leader` | リーダー | 担当取引先の閲覧・編集。サマリーはleader/memberのみ選択可。管理機能へのアクセス不可。 |
| `member` | 担当 | 担当取引先の閲覧・編集のみ。 |

### 2.2 データ整合性・可用性

- **カスケード削除**: 上位階層（取引先・部署）の削除時に、紐づく下位データ（案件・ログ）を連鎖的に削除し、不整合を防止。
- **UXレスポンス**: GASの非同期通信中に「保存中」の状態を表示し、操作の競合や不安を解消。

### 2.3 運用保守

- **設問管理**: 管理者がスプレッドシートや専用UIから、月次チェック項目の追加・削除・並び替えを動的に行えること。

### 2.4 制約事項

- **ストレージ**: Googleドライブおよびスプレッドシートのクォータ制限（API実行時間、容量等）に依存。
- **ブラウザ**: 最新のGoogle Chromeを推奨し、iPhone/Androidでのレスポンス表示（ズーム防止等）を考慮。
