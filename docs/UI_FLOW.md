# 取引先ターゲット管理アプリ - 画面遷移図・UI構成

## 1. 基本構造

本アプリはシングルページアプリケーション (SPA) 構成を採用しており、ページ遷移なしで上部のタブ切り替えによって各機能へアクセスします。

## 2. タブ構成

1.  **📝 活動＆アクション (Tab 0)**
    - **メイン操作**: 対象取引先を選択し、進行中の案件に対して活動ログ（訪問記録）を入力。
    - **状況更新**: ログ入力と同時に案件のステージ変更やネクストアクションの設定が可能。
    - **リスト表示**: 進行中の案件一覧（期限超過は赤色強調）と全期間の活動履歴を表示。案件カードの「📋 履歴」ボタンでステージ変更履歴をモーダル表示。
    - **CSVエクスポート**: 「📊 データCSV出力」ボタンでモーダルを起動。取引先・案件・期間の3フィルターを指定して18列統一フォーマットの CSV をダウンロード（admin/manager は全件、leader/member は自担当分のみ）。「📊 案件別進捗レポート（全体）」ボタンでキャンペーン名検索による全件進捗レポートを出力（全登録ユーザーが利用可能）。
    - **権限制御**: `manager` はログ入力フォームが非表示（閲覧専用）。`manager` は全取引先を閲覧可。
    - **他担当者閲覧**: `member`/`leader` は担当者セレクターで他担当者の取引先を閲覧専用で参照可能。選択中は編集操作が非表示。

2.  **🔭 取引先ダッシュボード (Tab 1)**
    - **可視化**: 特定の取引先における「アクティブ案件の進捗」「クロージング実績」「直近の訪問履歴」「期限超過アクション」をカード形式で一覧表示。
    - **他担当者閲覧**: `member`/`leader` は担当者セレクターで他担当者の取引先ダッシュボードを参照可能（閲覧専用）。

3.  **📊 全体サマリー＆レビュー (Tab 2)**
    - **KPI表示**: 指定月における「接点部署数」「同行回数」「提案中案件数」を集計。
    - **レビュー**: 担当者による月次セルフチェック回答と、`admin`/`manager` による評価・コメント入力。
    - **全体俯瞰**: 全取引先の案件状況をステージ・取引先名フリーワードでフィルタリングして確認可能。
    - **ユーザー選択**: `admin` は全ロール、`manager`/`leader` は `leader`/`member` のみ選択可。

4.  **📈 統計 (Tab 3)**
    - **グラフビュー切替**: 「案件概況」タブ（ステージ別ドーナツ・受注失注ドーナツ）と「活動状況」タブ（月別活動件数棒グラフ・担当者別案件数横棒グラフ）を切り替え。1画面に2グラフ表示。
    - **担当者フィルタ**: `admin`/`manager` のみ表示される担当者セレクトで個人データに絞り込み可能。「全体」選択時は担当者別横棒グラフも表示。
    - **キャッシュ**: 初回クリック時のみ GAS を呼び出し、以降はキャッシュ描画。担当者切り替え時はリロード。
    - **ローディング**: タブ初回表示時に `showOverlay("📊 統計データを読み込み中...")` オーバーレイを表示。

5.  **🏥 取引先登録・編集 (Tab 4)**
    - **マスタ保守**: 取引先の基本プロフィール編集。部署および案件の新規登録・編集・削除。
    - **参照登録**: 既存のマスターリストから取引先情報を検索し、ワンクリックで反映。
    - **権限制御**: `manager` はタブ自体が非表示。取引先削除は `admin` のみ。

6.  **⚙️ 設問管理 (Tab 5 / admin・manager限定)**
    - **動的設定**: 月次レビューで使用するチェック項目の追加、並び替え、非表示設定。

## 3. 共通UI・モーダル

- **🚀 クイック登録モーダル**: どの画面からでも「取引先 ＞ 部署 ＞ 案件」をウィザード形式で連続登録できるショートカット。
- **⏳ クラウド同期ボタン**: ヘッダーに配置。メモリ上の変更をバックエンドのスプレッドシートへ一括送信。`manager` には非表示。
- **📋 ターゲット取引先CSVボタン**: ヘッダーに配置（クラウド同期ボタン隣）。登録中の全対象取引先を CSV でダウンロード。`admin`/`manager` のみ表示（`admin-only` クラス）。
- **💬 SweetAlert2 ダイアログ**: 削除確認・エラー通知・操作結果をアニメーション付きダイアログで表示。削除確認は「キャンセル / 削除する」の2ボタン形式。エラー時は「再試行 / 閉じる」で即時リトライ可能。
- **✅ トースト通知**: 保存成功時に画面右下に緑色のトーストが2秒間表示される。
- **⏳ ローディングオーバーレイ**: GAS通信待ち中（保存・統計読み込みなど）、画面中央に半透明オーバーレイを表示してユーザー操作をブロック。並列非同期呼び出しにも対応した参照カウント方式で制御。
- **🔍 検索可能セレクト (Tom Select)**: 取引先選択プルダウンにキーワード検索機能を搭載。取引先数が多い場合でも名前の一部を入力して絞り込める。

## 4. 案件カード表示仕様

- **優先度による左ボーダー色**: 高=赤 (`#DC2626`) / 中=アンバー (`#D97706`) / 低・未設定=グレー (`#CBD5E1`)
- **期限超過**: 背景色が薄赤 (`#FEF2F2`) に変化し、期限日に ⚠️ アイコンを表示。
- **ステージバッジ**: 各カード右上に現在のステージを色付きバッジで表示。
- **ホバー効果**: カード上でマウスをホバーすると背景色が変化し、クリック可能であることを視覚的に示す。
- **📋 履歴ボタン**: 案件カードのバッジ横に配置。クリックでステージ変更履歴（変更日時・ステージ・変更者）を SweetAlert2 モーダルで表示。

## 5. 画面遷移ロジック

- JavaScriptの `switchTab(index)` 関数が `content` クラスの表示/非表示を切り替えます。
- 取引先の選択（プルダウン変更）をトリガーに、関連する案件リストやダッシュボードが非同期で再描画されます。
- キャンペーンマスターは起動時に `getActivePlans()` で取得し、案件フォームの「案件名」コンボボックス（`<datalist>`）に期間中のキャンペーン名を動的に表示します。
