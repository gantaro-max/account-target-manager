# 取引先ターゲット管理アプリ - 操作説明書（責任者向け）

**対象ロール**: `manager`（責任者）  
**最終更新**: 2026-07-07

---

## はじめに

本書は `manager`（責任者）ロールを持つユーザー向けの操作説明書です。  
責任者は以下の権限を持ちます。

| 操作 | 可否 |
| :--- | :--- |
| 全担当者の取引先・案件・活動ログを閲覧 | ✅ 可 |
| 担当者別・全体の統計グラフを確認 | ✅ 可 |
| 全担当者分のCSVダウンロード | ✅ 可 |
| 月次セルフチェック設問の追加・非表示・削除 | ✅ 可 |
| キャンペーンマスター（案件名候補）の追加・編集・削除 | ✅ 可 |
| 活動ログ・案件・取引先・部署の直接編集 | ❌ 不可（閲覧のみ） |

> 日常的な活動ログ入力・案件登録などの操作については [営業担当者向けマニュアル](MANUAL_MEMBER.md) を参照してください。

---

## 1. 画面構成

| タブ | 主な用途 |
| :--- | :--- |
| 📝 活動＆アクション | 担当者の活動ログ・案件を閲覧（担当者セレクターで切替） |
| 🔭 取引先ダッシュボード | 取引先別の進捗を閲覧（担当者セレクターで切替） |
| 📊 全体サマリー＆レビュー | KPI確認・担当者のセルフチェック内容を確認 |
| 📈 統計 | 全体・担当者別グラフで営業状況を把握 |
| ⚙️ 設問管理 | 月次設問・キャンペーンマスターを管理（**責任者の主要管理エリア**） |

> 🏥 **取引先登録・編集** タブは `manager` ロールでは非表示です（`admin` 専用）。

---

## 2. 全担当者データの閲覧

### 担当者セレクターの使い方

📝 **活動＆アクション** タブおよび 🔭 **取引先ダッシュボード** タブの取引先セレクター左側に、**担当者セレクター**があります。

1. 担当者セレクターから確認したい担当者を選択する
2. 取引先セレクターがその担当者の担当取引先一覧に切り替わる
3. 取引先を選択すると活動ログ・案件・履歴が閲覧できる

> `manager` ロールでは **活動ログのフォームや編集ボタンは非表示**になります（閲覧専用）。

---

## 3. 統計グラフを活用する

📈 **統計** タブでは全担当者の営業状況をグラフで確認できます。

### 担当者フィルター

画面上部の**担当者セレクト**で以下を切り替えられます。

| 選択 | 表示内容 |
| :--- | :--- |
| **全体** | 全担当者の集計データ。担当者別横棒グラフも表示される |
| **個人名** | その担当者のデータのみ表示 |

### グラフの種類

| タブ | グラフ |
| :--- | :--- |
| **案件概況** | ステージ別案件数（ドーナツ）・受注/失注/進行中（ドーナツ） |
| **活動状況** | 月別活動件数（棒グラフ）・担当者別案件数（横棒グラフ） |

> グラフは初回タブ表示時に読み込まれます。最新データを取得したい場合は「🔄 更新」ボタンをクリックしてください。

---

## 4. CSVデータをダウンロードする

### 📊 データCSV出力（Tab 0 ツールバー）

📝 **活動＆アクション** タブの「📊 データCSV出力」ボタンから、**全担当者分**のデータを18列統一フォーマットでダウンロードできます。

1. 「📊 データCSV出力」ボタンをクリックしてモーダルを開く
2. ① **取引先**を選択（「全取引先」または特定の取引先）
3. ② **案件**を選択（テキスト入力で絞り込み可。「全案件」でも可）
4. ③ **期間**を選択（全件 / 直近1ヶ月 / 期間指定）
5. 「📥 CSV出力」をクリック

**出力列（18列）**: 担当者名・取引先コード・取引先名・担当MS・部署名・案件名・対象製品・進捗ステージ・受注/失注・最新課題メモ・ネクストアクション・アクション担当者・次回予定日・訪問日・活動内容・同行者・添付URL・更新日時

- `manager` は全担当者分が出力されます
- ファイルは BOM付きUTF-8 形式のため、Excel でそのまま開いても文字化けしません
- ステージはラベル付き（例: `2：ニーズ確認中`）で出力されます

### 📊 案件別進捗レポート（Tab 0 ツールバー）

キャンペーン名（部分一致）で絞り込んだ全担当者の進捗＋活動履歴を出力します。**全登録ユーザーが利用可能**です。

### 📋 ターゲット取引先CSV（ヘッダー）

画面上部ヘッダーの「📋 ターゲット取引先CSV」ボタンで、現在登録中の全対象取引先の基本情報（担当者名・取引先コード・取引先名・担当パートナー名・優先度・特記事項の6列）を即時ダウンロードできます。`admin`/`manager` のみ表示されます。

## 5. ⚙️ 設問管理タブ

### アクセス方法

上部タブ右端の **「⚙️ 設問管理」** をクリックすると管理エリアが開きます。  
このタブは `manager`・`admin` のみ表示されます。

設問管理タブには2つの管理エリアがあります。

---

### 5-1. 月次セルフチェック設問の管理

全担当者の **📊 全体サマリー＆レビュー** タブに表示される月次チェック設問を管理します。

#### 設問を追加する

1. 画面上部のテキスト入力欄に設問文を入力する
2. 「**追加**」ボタンをクリック
3. 設問が一覧に追加される
4. 「**🔄 状態を保存**」ボタンをクリックして確定する

#### 設問を並び替える

一覧内の設問をドラッグ＆ドロップで順番を変更できます。  
変更後は「**🔄 状態を保存**」ボタンをクリックしてください。

#### 設問を非表示にする（推奨）

一覧内の設問の「**非表示**」ボタンをクリックします。  
担当者の月次レビュー画面から消えますが、管理画面には `[非表示]` バッジ付きで残り、**過去の回答データは保持**されます。  
再度表示に戻したい場合は、同じ行の「**表示に戻す**」ボタンをクリックしてください。

#### 設問を完全削除する

一覧内の設問の「**完全削除**」ボタンをクリックします。  
スプレッドシートから物理削除されます。  
削除後は「**🔄 状態を保存**」ボタンをクリックしてください。

> ⚠️ 完全削除すると、過去のレビューデータとの紐付けが失われます。通常は「非表示」を使用してください。

---

### 5-2. キャンペーンマスターの管理

案件フォームの「案件名（キャンペーン名）」プルダウンに表示される候補リストを管理します。  
有効期間中のキャンペーンのみが担当者の案件フォームに候補として表示されます。

#### キャンペーン一覧の見方

| 列 | 内容 |
| :--- | :--- |
| キャンペーン名 | 案件フォームに表示される名称 |
| 対象製品 | キャンペーンに紐づく商材（案件の対象製品欄に自動反映される） |
| 期間 | 有効期間（この期間中のみ担当者の候補リストに表示） |
| 状態 | 期間に基づく現在の状態（`進行中` / `開始前` / `終了` / `期間未設定`） |

#### キャンペーンを追加する

1. フォームエリアに以下を入力する：

   | 項目 | 内容 |
   | :--- | :--- |
   | キャンペーン名 ※必須 | 例：春の感染対策キャンペーン |
   | 対象製品 | 例：消毒液シリーズ（案件フォームの対象製品欄に自動反映） |
   | 説明・備考 | 管理用メモ（任意） |
   | 開始日 | 担当者の候補リストへの表示開始日 |
   | 終了日 | 担当者の候補リストへの表示終了日 |

2. 「**💾 保存**」ボタンをクリック
3. 一覧に新しいキャンペーンが追加される

> **開始日・終了日を空欄にした場合**: キャンペーンは常に候補リストに表示されます（期間制限なし）。

#### キャンペーンを編集する

1. 一覧の対象キャンペーンの「**✏️ 編集**」ボタンをクリック
2. フォームエリアが「✏️ キャンペーンを編集中」モードに切り替わる
3. 内容を修正して「**💾 保存**」ボタンをクリック
4. 「キャンセル」ボタンで変更を破棄して新規追加モードに戻れる

#### キャンペーンを削除する

1. 一覧の対象キャンペーンの「**🗑️ 削除**」ボタンをクリック
2. 確認ダイアログで「**OK**」をクリック

> ⚠️ 削除しても過去の案件に登録済みのキャンペーン名はそのまま保持されます（案件データの破壊は起きません）。

## 6. よくある質問

**Q. データが表示されない / 担当者セレクターが表示されない**  
A. ページをリロード（F5）してください。初回読み込み時にすべてのデータをGASから取得します。

**Q. ⚙️ 設問管理タブが表示されない**  
A. `manager` ロールが正しく設定されていない可能性があります。管理者（admin）にスプレッドシートの `users` シートでロール設定を確認してもらってください。

**Q. キャンペーンを追加したのに担当者の候補リストに表示されない**  
A. 開始日・終了日の設定を確認してください。今日の日付が有効期間外の場合は候補に表示されません。担当者がページをリロードすると最新のキャンペーンリストが反映されます。


**Q. 出力先スプレッドシートをゴミ箱に入れてしまった**  
A. 次回トリガー実行時（または再度トグルを ON にしたとき）に自動で新しいスプレッドシートが作成されます。古い SS は Drive のゴミ箱から手動で削除してください。

**Q. 設問の変更が担当者の画面に反映されない**  
A. 担当者がページをリロードすると反映されます。「🔄 状態を保存」ボタンを押しただけでは、既に開いているタブには自動反映されません。
